ℹ️ 2.2.6 정보이론

확률이 작은 사건일수록 더 많은 정보를 준다는 직관에서 시작합니다.

자기정보

I(X) = -log P(X)

희귀한 사건일수록 정보량이 큽니다.

엔트로피

H(X) = E[-log P(X)]

확률변수의 평균 정보량, 즉 평균적인 불확실성입니다.

주사위 예: 모든 사건의 확률이 같을 때 예측이 가장 어렵고 엔트로피가 최대가 됩니다.

Cross Entropy

H(P,Q) = -Σ P(x) log Q(x)

P는 실제 분포, Q는 예측 분포.

KL Divergence

KL(P||Q)=ΣP(x)log(P(x)/Q(x))

P와 Q의 차이를 측정하며 P=Q이면 0입니다.

H(P,Q) = H(P) + KL(P||Q)

P가 고정이면 교차엔트로피 최소화는 KL divergence 최소화와 연결됩니다. KL은 비대칭이므로 엄밀한 거리 함수는 아닙니다.

🧭 2.3 최적화

훈련집합에 의해 정의된 목적함수를 가장 작게 만드는 파라미터를 찾습니다.

매개변수 공간

모델을 선택한 뒤 θ 공간을 탐색해 J(θ)가 최소인 지점을 찾습니다.

Global / Local Optimum

고차원에서는 전역 최적해 대신 충분히 좋은 지역 최적해를 얻고 만족하는 경우가 많다고 설명합니다.

탐색의 문제: exhaustive search는 차원이 조금만 커져도 불가능해지고, random search는 목적함수가 줄어드는 방향을 이용하지 않습니다.

∇ 미분과 Gradient

1차 미분

함수값이 증가하는 방향과 변화율을 알려줍니다. 따라서 목적함수를 줄이려면 -f′(x) 방향으로 움직입니다.

수치적 방법

기계학습은 차원이 높고 함수가 복잡하므로 f′(x)=0을 직접 푸는 분석적 방법보다 조금씩 이동하는 수치적 방법을 사용합니다.

개념핵심연결
편미분여러 변수 각각을 독립적으로 미분많은 파라미터
Gradient편미분을 모은 벡터가장 빠른 증가 방향
Hessian2차 편도함수 행렬곡률
Jacobian벡터 함수의 1차 미분 행렬다입력·다출력 변화율
Chain Rule합성함수 미분오류 역전파

⬇️ 경사 하강 알고리즘

θ ← θ - ρ ∇J(θ)

gradient의 반대 방향으로 학습률 ρ만큼 이동합니다.

Batch GD

전체 샘플 gradient를 평균낸 뒤 한 번 갱신합니다.

SGD

샘플 하나마다 gradient를 계산하고 즉시 갱신합니다.

Epoch

전체 훈련집합을 한 번 모두 사용하는 반복 단위입니다. SGD는 새 epoch마다 샘플 순서를 섞습니다.

Learning Rate: gradient는 방향을 알려줄 뿐 이동량은 알려주지 않으므로 학습률이 보폭을 정합니다.

🎯 목적함수: MSE와 Cross Entropy

MSE

MSE ∝ Σ(y-o)²

예측과 실제값의 차이가 클수록 큰 벌점.

Binary Cross Entropy

-[y log p̂ +(1-y)log(1-p̂)]

정답과 예측 확률이 어긋날수록 손실이 커집니다.

딥러닝 연결: 자료는 MSE보다 교차엔트로피를 분류·딥러닝 목적함수로 주로 사용한다고 설명합니다.
