1.1 🤖 기계 학습이란

정의

특정 응용 영역에서 발생하는 데이터(경험)를 이용해 더 높은 성능으로 문제를 해결하는 컴퓨터 프로그램을 만드는 작업입니다.

핵심 전환

초창기 AI의 지식기반·규칙기반 방식은 사람이 규칙을 명시하기 어려운 문제에서 한계가 컸고, 주도권은 데이터 중심 접근으로 이동했습니다.

핵심 질문
사람이 규칙을 정확히 적어주지 않아도, 예시와 경험을 통해 성능이 점점 좋아지는 기계를 만들 수 있는가?

데이터 유형

범주형·이산형 / 질적순위형5점 척도, 등급, 학점

1.2 📐 특징 공간에 대한 이해

샘플을 숫자 벡터로 바꾸면 각 샘플은 특징 공간 안의 한 점이 됩니다.

1차원

특징이 하나면 수직선 위의 점으로 표현합니다.

2차원

x=(x₁,x₂)ᵀ

예: 몸무게·키, 체온·두통.

d차원

x=(x₁,…,x_d)ᵀ

MNIST는 784차원 특징 벡터로 볼 수 있습니다.

차원의 저주
차원이 커질수록 가능한 공간의 크기는 폭발적으로 증가하지만 실제 샘플은 그 공간에 매우 희소하게 놓입니다.

표현 학습 · Representation Learning

좋은 특징 공간을 자동으로 찾는 작업입니다. 딥러닝은 여러 은닉층을 통해 저급 특징에서 고급 특징으로 계층적인 표현을 학습합니다.

1.3 🧱 데이터에 대한 이해

데이터 생성 과정

실제 머신러닝 문제에서는 데이터가 어떤 과정에서 생성되는지 완전히 알 수 없습니다. 주어진 훈련집합을 통해 예측 모델 또는 생성 모델을 근사합니다.

데이터베이스의 품질

응용 환경에 맞는 충분히 다양하고 충분한 양의 데이터가 중요합니다. 정면 얼굴만 학습하면 기울어진 얼굴에서 성능이 떨어질 수 있습니다.

Iris

고전적인 4개 특징·3개 붓꽃 종 분류 데이터.

MNIST

손글씨 숫자 데이터. 훈련 60,000개, 테스트 10,000개.

ImageNet

대규모 자연영상 분류 데이터셋의 대표 사례.

매니폴드 가정
고차원 전체 공간은 거대하지만 실제 데이터는 그 안의 훨씬 작은 저차원 구조에 모여 있을 수 있다는 관점입니다.

1.4 📈 간단한 기계 학습의 예 · 선형 회귀

y = wx + b

w와 b가 모델의 매개변수(parameter)입니다.

① 모델 선택

직선이라는 함수 형태를 선택합니다.

② 목적함수

예측과 실제값의 차이를 수치화합니다.

③ 최적화

목적함수가 작아지도록 w,b를 반복해서 개선합니다.

MSE = 평균[(fθ(xᵢ)-yᵢ)²]

자료에서는 선형 회귀 목적함수로 평균제곱오차(MSE)를 사용합니다.

학습의 의미
처음에는 최적 매개변수를 모르므로 임의값에서 시작해 성능을 점점 개선합니다. 이 과정을 learning 또는 training이라 합니다.
궁극적인 목표
훈련집합을 완벽히 맞추는 것이 아니라, 훈련에 없던 새로운 샘플에서 오류를 줄이는 것. 이것이 generalization(일반화)입니다.

1.5 ⚖️ 모델 선택

Underfitting

모델 용량이 너무 작아 훈련 데이터 자체도 충분히 설명하지 못합니다.

Good Fit

핵심 패턴은 설명하되 잡음까지 따라가지는 않는 적절한 복잡도입니다.

Overfitting

모델이 너무 복잡해 훈련 데이터의 잡음까지 수용하고 새로운 데이터에서는 성능이 떨어집니다.

모델 복잡도BiasVariance경향
낮음큼작음과소적합 가능
높음작음큼과잉적합 가능

검증집합과 교차검증

모델 선택에는 훈련/테스트와 별도의 validation set이 필요할 수 있습니다. 별도 검증셋을 두기 어렵다면 훈련집합을 나눠 여러 번 학습·평가하고 평균을 사용하는 cross validation을 활용합니다.

1.6 🧯 규제 · Regularization

현대 머신러닝에서는 충분한 용량의 모델을 선택한 뒤, 모델이 과하게 복잡해지지 않도록 규제를 적용하는 전략을 사용합니다.

Data Augmentation

새 데이터를 수집하는 비용이 크므로 기존 샘플에 이동, 회전, 크기 변화, 워핑, 잡음 추가 등을 적용해 학습 데이터를 늘립니다. 단, 부류 소속이 바뀌지 않도록 해야 합니다.

Weight Decay

목적함수에 가중치 크기에 대한 규제항을 더해 계수가 지나치게 커지는 것을 막습니다. 오류는 작고 계수는 작은 더 매끄러운 해를 유도합니다.

1.7 🧭 기계 학습 유형

유형데이터 상황대표 과업
지도학습X와 Y 모두 있음회귀, 분류
비지도학습X만 있음군집화, 밀도추정, 특징공간 변환
강화학습연속된 행동 이후 보상 제공게임, 순차적 의사결정
준지도학습일부만 X,Y / 나머지는 X만소량 라벨 + 대량 무라벨 학습

Offline vs Online

미리 수집한 데이터로 학습 후 적용할지, 새 샘플로 점증적 학습할지 구분합니다.

Deterministic vs Stochastic

같은 데이터에서 같은 모델이 나오는지, 난수 영향으로 다른 모델이 나올 수 있는지의 구분입니다.

Discriminative vs Generative

분별 모델은 P(y|x)에, 생성 모델은 P(x) 또는 P(x|y)에 관심을 둡니다.

1.8 🕰️ 기계 학습의 과거와 현재, 미래

초기

컴퓨터가 지능적 작업도 할 수 있을 것이라는 기대에서 인공지능이 시작됐습니다.

전환

규칙을 손으로 모두 작성하는 방식에서 데이터와 학습 알고리즘 중심으로 이동했습니다.

현대

딥러닝과 표현 학습이 중요해졌고, 음성·문자·영상·얼굴 인식 등 다양한 응용이 발전했습니다.

이 장의 관점
인공지능은 더 넓은 목표이고, 기계학습은 데이터를 통해 문제 해결 규칙을 학습하는 핵심 방법이며, 딥러닝은 그 기계학습을 구현하는 중요한 기술 흐름으로 소개됩니다.

✅ 1장 복습 체크

Q. 머신러닝의 최종 목표는 훈련 정확도인가?

아닙니다. 이 장에서는 훈련에 없던 새로운 샘플에서 오류를 최소화하는 일반화 능력을 궁극적 목표로 봅니다.

Q. 왜 복잡한 모델이 항상 좋은 것은 아닌가?

훈련 데이터의 잡음까지 맞추면 훈련 성능은 높아져도 새로운 데이터에서 성능이 떨어지는 과잉적합이 생길 수 있기 때문입니다.
