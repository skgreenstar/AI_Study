ML 연결
머신러닝 데이터는 결국 숫자 배열입니다. 한 샘플을 벡터로, 여러 샘플을 행렬로 표현하고, 모델 학습은 이 배열의 곱·합·거리·방향을 계산하는 과정으로 볼 수 있습니다.

🧱 데이터는 어떻게 벡터와 행렬이 되나?

강의자료는 Iris 데이터를 이용해 한 꽃의 네 특징을 하나의 feature vector로, 150개 샘플 전체를 design matrix로 표현합니다.

Scalar · 스칼라

숫자 하나. 예: 온도 95.2, 학습률 0.001.

Vector · 벡터

한 샘플의 여러 특징을 묶은 1차원 배열. 크기와 방향을 가집니다.

Matrix · 행렬

여러 벡터를 행/열로 쌓은 2차원 배열. 훈련집합을 담으면 design matrix가 됩니다.

x = [5.1, 3.5, 1.4, 0.2]ᵀ ∈ R⁴

Iris 샘플 하나 = 꽃받침 길이·너비 + 꽃잎 길이·너비의 4차원 특징 벡터

X ∈ Rⁿˣᵈ

n개 샘플 × d개 특징. 머신러닝에서 가장 자주 보는 데이터 행렬 형태입니다.

Tensor · 텐서
강의자료는 3차원 이상의 숫자 배열을 텐서로 소개하고, 스칼라=0차원 텐서, 벡터=1차원, 행렬=2차원으로 포괄해 설명합니다. RGB 이미지는 높이×너비×채널의 3차원 예가 됩니다.

📐 벡터에서 꼭 잡아야 할 3개

① 내적 · Dot Product

aᵀb = Σ aᵢbᵢ

두 벡터의 대응 성분을 곱해 모두 더합니다.

방향이 얼마나 비슷한지, 한 벡터가 다른 방향으로 얼마나 놓였는지 측정하는 핵심 연산입니다.

② 노름 · Norm

||x||₂ = √Σxᵢ²

벡터의 길이. 2-norm은 Euclidean norm입니다.

벡터를 길이 1로 나누면 unit vector가 됩니다.

③ 코사인 유사도

cos θ = aᵀb /(||a||·||b||)

길이 효과를 제거하고 방향의 유사도를 봅니다.

문서·임베딩 유사도에서 자주 만나는 형태입니다.

ML 연결
거리 기반 모델은 노름, 임베딩 검색은 코사인 유사도, 선형모델·신경망은 내적을 반복적으로 사용합니다. “벡터 연산”은 실제 모델 계산 그 자체와 연결됩니다.

🧭 선형독립 · 기저 · Rank

“이 벡터가 정말 새로운 방향을 추가하는가?”를 판단하는 개념들입니다.

Linear Combination · 선형결합

c = α₁a + α₂b

기존 벡터에 계수를 곱해 더해서 새 벡터를 만듭니다.

기저벡터의 선형결합으로 만들어지는 전체 영역이 vector space입니다.

Linear Independence · 선형독립

어떤 벡터도 나머지 벡터들의 선형결합으로 만들 수 없다면 서로 선형독립입니다. 반대로 하나라도 나머지 조합으로 표현되면 선형종속입니다.

Basis · 기저

공간을 만드는 최소한의 독립 방향들.

Orthonormal Basis

서로 직교하고 각 길이가 1인 기저.

Rank · 계수

행렬 안에서 선형독립인 행(또는 열) 벡터의 수.

ML 연결
특징 열들이 서로 거의 중복되면 실제 정보 차원은 낮아집니다. Rank는 “독립적인 정보 방향이 몇 개인가”를 보는 출발점이고, 차원축소와 다중공선성 이해로 이어집니다.

▦ 행렬: 모델 계산의 작업대

개념핵심머신러닝에서 보는 장면
Transpose Aᵀ행과 열을 뒤집음XᵀX, covariance, gradient 계산
Matrix Multiplication ABA의 열 수 = B의 행 수Dense layer: XW+b
Identity I곱해도 원래 행렬 유지역행렬·고유값 식
Determinant det(A)정방행렬을 하나의 값으로 요약역행렬 존재 여부와 연결
Inverse A⁻¹AA⁻¹=I선형방정식 해석, 정규방정식의 이론적 형태
Frobenius Norm행렬 원소 제곱합의 제곱근행렬 크기·오차·regularization
중요: 행렬곱은 일반적으로 교환법칙이 성립하지 않습니다. 즉 AB ≠ BA입니다. 딥러닝의 shape 오류 대부분은 이 차원 규칙을 놓쳤을 때 생깁니다.

λ 고유값과 고유벡터: 변환 후에도 방향이 유지되는 축

행렬 A로 변환했을 때 방향은 그대로이고 길이만 λ배 되는 특별한 벡터가 고유벡터입니다.

Ax = λx

x: eigenvector(고유벡터), λ: eigenvalue(고유값). x는 0이 아닌 벡터입니다.

Eigenvector

행렬 변환이 작용해도 방향이 유지되는 축. 상수배도 같은 방향의 고유벡터가 되므로 보통 길이 1로 정규화합니다.

Eigenvalue

그 특별한 방향이 변환 후 얼마나 늘거나 줄어드는지를 나타내는 값입니다.

det(A - λI) = 0

특성방정식을 풀어 고유값을 구하고, 각 λ에 대해 (A-λI)x=0을 풀어 고유벡터를 찾습니다.

ML 연결 · PCA
공분산 행렬의 고유벡터는 데이터가 퍼지는 주요 방향이 되고, 대응 고유값은 그 방향의 분산 크기를 나타냅니다. 큰 고유값의 방향부터 선택하면 PCA의 주성분이 됩니다.

◇ 대각화: 복잡한 변환을 축별 스케일링으로 바꾸기

강의자료는 정방행렬·대칭행렬의 대각화를 다루며, 모든 행렬이 대각화 가능한 것은 아니라고 설명합니다.

A = C D C⁻¹

D는 대각행렬, C의 열에는 고유벡터들이 들어갑니다. 즉 좌표계를 고유벡터 축으로 바꾸면 변환을 대각 성분별 독립적인 스케일링으로 볼 수 있습니다.

① Change Basis

고유벡터 좌표계로 이동

② Scale

각 축을 λ만큼 확대·축소

③ Return

원래 좌표계로 복원

대칭행렬의 좋은 성질
실수 대칭행렬은 서로 직교하는 고유벡터를 가질 수 있어 직교대각화가 가능하며, 이 성질이 covariance matrix와 PCA를 다룰 때 특히 중요합니다.

Σ SVD: 정방행렬이 아니어도 분해한다

강의자료는 고유값 분해가 정사각행렬에만 적용된다는 한계를 짚고, 일반적인 n×m 행렬에는 특이값 분해(SVD)를 사용합니다.

A = U Σ Vᵀ

U와 V는 직교 방향, Σ는 중요도를 나타내는 singular value(특이값)를 대각에 담습니다.

Σ

V

ML 연결
큰 특이값 몇 개만 남기면 원래 행렬의 중요한 구조를 보존하면서 저랭크 근사를 만들 수 있습니다. 차원축소, 압축, 잡음 제거, 잠재구조 분석의 수학적 기반으로 이어집니다.

✅ 이해했는지 확인

Q. 벡터와 행렬을 가장 짧게 구분하면?

벡터는 한 샘플의 특징 묶음, 행렬은 여러 벡터를 쌓은 구조라고 기억하면 머신러닝 문맥에서 가장 직관적입니다.

Q. 고유벡터가 왜 중요한가?

복잡한 선형변환에서도 방향이 바뀌지 않는 축이기 때문입니다. 그 축을 기준으로 변환을 보면 구조가 단순해지고, PCA처럼 중요한 데이터 방향을 찾는 데 활용됩니다.

Q. SVD는 한 문장으로?

어떤 행렬이든 입력 방향(V), 중요도(Σ), 출력 방향(U)으로 분해해 핵심 구조를 드러내는 방법입니다.
