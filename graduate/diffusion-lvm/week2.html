1. Score Function: 확률 지형의 나침반

데이터가 몰린 곳을 산꼭대기라고 생각하세요. Score는 현재 위치에서 확률이 가장 빠르게 높아지는 방향을 가리키는 화살표입니다.

↗↗↑
Score s(x) = ∇x log p(x)

∇x : x를 조금 움직였을 때 얼마나 변하는가?
log p(x) : 현재 위치가 데이터다운 정도
s(x) : 더 데이터다운 곳으로 가는 방향과 세기

왜 p(x)의 기울기가 아닌가?

정규화 상수를 포함한 p(x)는 고차원에서 계산하기 어렵고, 저밀도에서는 값이 너무 작아 수치적으로 불안정합니다.

왜 log를 씌우나?

곱을 합으로 바꾸고 극도로 작은 확률을 다루기 쉬워집니다. 방향은 p(x)의 기울기와 같습니다.

정규화 상수는?

p(x)=p̃(x)/Z
∇log p(x)=∇log p̃(x)

x와 무관한 Z는 미분하면 사라집니다.

2. Score Matching에서 Denoising Score Matching으로

진짜 Score는 알 수 없으니 모델 sθ(x)가 흉내 내게 하고 싶지만, 원본 데이터의 밀도 기울기는 직접 관측되지 않습니다. 해결책은 우리가 답을 아는 Gaussian noise를 일부러 더하는 것입니다.

깨끗한 x₀훈련 이미지
+
Gaussian ε우리가 뽑은 노이즈
→
오염된 x̃x₀ + σε
→
정답 Score분석적으로 계산
x̃ = x₀ + σε
조건부 Gaussian의 score = ∇x̃ log q(x̃|x₀) = -(x̃-x₀)/σ² = -ε/σ

LDSM = E || sθ(x̃) - (-ε/σ) ||²
수식 해부: 모델에게 “깨끗한 이미지를 직접 맞혀라”가 아니라, “현재 noisy point에서 원본 쪽으로 돌아갈 화살표를 맞혀라”라고 가르치는 것입니다.

Sliced SM임의 벡터 방향으로 투영고차원 계산을 근사

3. NCSN: 하나의 노이즈 높이로는 길이 끊긴다

작은 σ는 데이터 근처에서 정밀하지만 멀리 있는 점을 안내하지 못합니다. 큰 σ는 멀리까지 지형을 연결하지만 세부가 흐립니다. 그래서 여러 σ를 함께 배웁니다.

σ₁ 매우 큼섬들을 하나로 연결
σ₂ 큼대략적 형태
σ₃ 작음윤곽 정밀화
σ₄ 매우 작음원본 분포 접근
Noise Conditional Score Network
sθ(x̃, σ) ≈ ∇x̃ log pσ(x̃)

L = Eσ,x₀,ε[ λ(σ) || sθ(x₀+σε,σ) + ε/σ ||² ]

Annealed Langevin Dynamics: 넓게 찾고 점점 정밀하게

큰 σ노이즈에서 출발
→

→
σ 감소형태 구체화
→
반복고밀도 영역으로
→
샘플선명한 이미지
x ← x + α · sθ(x,σ) + √(2α) · z
첫 항: Score가 가리키는 고밀도 방향  |  둘째 항: 새로운 모드를 탐색하는 랜덤 킥

4. SDE: 계단식 노이즈를 연속 시간으로

DDPM의 유한한 단계와 NCSN의 노이즈 레벨을 t∈[0,T]의 연속 흐름으로 통합합니다.

g(t)dW

dx : 아주 짧은 시간의 위치 변화
f(x,t)dt : 평균적으로 밀어주는 결정론적 이동
g(t)dW : Wiener process가 만드는 확률적 노이즈

Variance Preserving SDE

신호를 줄이고 노이즈를 늘리되 전체 분산 규모가 폭발하지 않게 설계합니다.

대표 연결: DDPM

Variance Exploding SDE

원본에 점점 큰 노이즈를 더해 분산이 커지는 흐름입니다.

대표 연결: NCSN
통합의 의미: DDPM과 Score Matching은 서로 떨어진 기술이 아니라, 어떤 f와 g를 선택하느냐에 따라 같은 SDE 프레임 안에서 설명되는 친척입니다.

5. 연속시간 Score Model의 학습 레시피

① x₀데이터 선택
→
② t시간 무작위 선택
→
③ xₜ해당 시간만큼 오염
→
④ sθ(xₜ,t)Score 예측
t ~ Uniform(0,T),   x₀ ~ pdata,   ε ~ N(0,I)
xt = μ(t)x₀ + σ(t)ε
target score = -(xt-μ(t)x₀)/σ(t)²
L = λ(t) || predicted score - target score ||²
왜 t를 무작위로 뽑나? 한 번의 학습에서 전체 시간 궤적을 돌지 않고도, 여러 미니배치가 서로 다른 노이즈 시점을 담당하여 전체 복원 지도를 배울 수 있기 때문입니다.

6. Reverse-time SDE: 확산을 거꾸로 돌린다

정방향은 데이터에 노이즈를 섞습니다. 역방향은 같은 Drift를 단순히 부호만 바꾸는 것이 아니라, 확산을 이기고 고밀도 영역으로 되돌아갈 Score 보정이 필요합니다.

➡️ Forward

구조 있는 데이터 → 평평한 Gaussian noise

⬅️ Reverse

Noise → Score가 데이터 밀집 영역으로 모음

Reverse SDE
dx = [ f(x,t) - g(t)² ∇xlog pt(x) ]dt + g(t)dW̄t

f : 정방향 drift
-g² · score : 확산을 보상하며 데이터 쪽으로 끌어당기는 핵심
dW̄ : 역시간에서도 남아 있는 확률적 움직임
Inference: xT~N(0,I)에서 시작하여 Euler-Maruyama 같은 수치 해법으로 시간을 T→0으로 이동하면 최종 이미지 x₀를 얻습니다.

7. PF-ODE: 랜덤 흔들림 없는 또 하나의 길

Reverse SDE와 같은 각 시간의 확률분포(marginal)를 유지하면서, 확률 항을 없앤 결정론적 ODE를 만들 수 있습니다.

Probability Flow ODE
dx = [ f(x,t) - ½ g(t)² ∇xlog pt(x) ]dt
중요: “각 시점의 분포가 같다”는 것이 “개별 샘플이 똑같은 길을 간다”는 뜻은 아닙니다. Reverse SDE는 흔들리며 가고, PF-ODE는 시작점이 같으면 같은 경로를 갑니다.

8. 어디에 연결해서 생각할까?

🖼️ 이미지 생성

순수 노이즈에서 여러 scale의 Score를 따라 자연 이미지 분포로 이동합니다.

🔧 산업 이상 탐지

정상 데이터의 Score를 학습하면 정상 분포에서 멀어진 샘플이나 복원 방향을 분석할 수 있습니다.

🧬 역문제

저해상도·결측·노이즈 관측에 데이터 prior와 관측 제약을 함께 적용해 가능한 원본을 복원합니다.

실무 선택 관점: 다양성이 중요하면 확률적 sampler, 재현성과 속도가 중요하면 ODE 계열 sampler를 고려합니다. 품질은 모델뿐 아니라 noise schedule, solver, NFE, guidance의 조합으로 결정됩니다.

헷갈리는 개념 바로잡기

🧩 Score는 분류 점수나 품질 점수인가요?

아닙니다. 여기서 Score는 ∇log p(x), 즉 입력 공간에서 확률밀도가 증가하는 방향을 나타내는 벡터입니다.

🧩 모델이 p(x)를 직접 배우나요?

정규화된 확률값 자체가 아니라 그 로그의 기울기를 배웁니다. 생성할 때는 이 방향장을 따라 이동해 데이터 분포의 샘플을 얻습니다.

🧩 노이즈를 넣으면 왜 학습이 쉬워지나요?

우리가 Gaussian noise를 직접 만들었기 때문에 조건부 분포의 Score 정답 -ε/σ를 알고 있습니다. 알 수 없던 밀도 추정을 지도학습 형태로 바꿉니다.

🧩 DDPM과 NCSN은 완전히 다른 모델인가요?

출발 표현은 다르지만 noise prediction과 score prediction은 스케일 변환으로 연결되며, VP/VE SDE라는 연속시간 틀에서 통합할 수 있습니다.

🧩 PF-ODE는 확률분포를 다르게 만드나요?

이론적으로 정확한 Score와 해법이 있다면 Reverse SDE와 같은 시간별 marginal density를 가집니다. 다만 개별 샘플의 trajectory는 다릅니다.

🧠 30초 복습

Q1. Score s(x)=∇log p(x)가 가리키는 방향은?

데이터의 확률밀도가 가장 빠르게 증가하는 방향입니다.

Q2. x̃=x₀+σε일 때 Gaussian 조건부 Score는?

-(x̃-x₀)/σ² = -ε/σ입니다.

Q3. SDE의 Drift와 Diffusion은 각각 무엇인가요?

Drift는 평균적인 결정론적 이동, Diffusion은 Wiener process가 만드는 확률적 흔들림입니다.

Q4. Reverse SDE와 PF-ODE의 가장 눈에 띄는 차이는?

Reverse SDE는 확률적이고 PF-ODE는 결정론적입니다.
