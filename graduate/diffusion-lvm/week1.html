2. Forward Process: 우리가 정한 규칙으로 이미지를 지운다

각 단계에서 이전 이미지 일부를 남기고 새로운 Gaussian noise를 섞습니다. βₜ는 t단계에서 얼마나 망가뜨릴지를 정하는 Noise Schedule입니다.

x₀깨끗함
x₁약한 노이즈
x₂
xₜ형태가 흐림
xT-1
xT거의 순수 노이즈
한 단계
q(xt|xt-1) = N(√(1-βt)xt-1, βtI)
xt = √αtxt-1 + √(1-αt)ε,   αt=1-βt
가장 중요한 지름길: x₁부터 순서대로 만들지 않아도, 누적 신호량 ᾱₜ를 쓰면 x₀에서 임의의 xₜ를 한 번에 만들 수 있습니다.
ᾱt = ∏s=1t αs
q(xt|x₀) = N(√ᾱtx₀, (1-ᾱt)I)
xt = √ᾱtx₀ + √(1-ᾱt)ε

√ᾱₜ는 남아 있는 원본 신호, √(1-ᾱₜ)는 섞인 노이즈의 양입니다.

3. Reverse Process: 알 수 없는 복원 규칙을 학습한다

Forward q는 우리가 만들었지만, xₜ에서 xₜ₋₁로 돌아가는 진짜 역조건부 분포는 직접 알 수 없습니다. 신경망이 평균 또는 노이즈를 예측해 pθ를 근사합니다.

q(xₜ|xₜ₋₁)
정방향
알려진 Gaussian
⇄
pθ(xₜ₋₁|xₜ)
역방향
신경망으로 학습
pθ(xt-1|xt) = N( μθ(xt,t), σt²I )

실전 재매개화: μθ를 직접 맞히는 대신 εθ(xt,t)로 섞였던 노이즈를 예측
왜 Gaussian으로 가정할 수 있나? Forward step을 매우 작게 만들면 연속된 두 시점의 역조건부 분포도 근사적으로 Gaussian이 됩니다. 복잡한 전체 생성 문제를 작은 Gaussian 복원들의 연쇄로 바꾸는 핵심입니다.

4. ELBO 계단: 최대우도가 노이즈 MSE가 되기까지

목표는 훈련 이미지 x₀의 log pθ(x₀)를 크게 만드는 것입니다. 하지만 모든 중간 상태를 적분해야 해서 직접 계산할 수 없습니다.

①

Lower Bound

Jensen 부등식으로 계산 불가능한 log-likelihood 아래에 계산 가능한 ELBO를 놓습니다.

②

KL로 분해

ELBO를 각 단계의 진짜 역분포와 모델 역분포 사이 차이로 펼칩니다.

③

Gaussian 계산

Bayes 법칙·Markov 성질·Gaussian 성질로 각 KL 항을 닫힌 형태로 계산합니다.

④

Noise MSE

상수와 가중치를 단순화하면 실제 학습은 예측 노이즈와 실제 노이즈의 제곱오차가 됩니다.

log pθ(x₀) ≥ ELBO

-ELBO ≈ Σt KL(q(xt-1|xt,x₀) || pθ(xt-1|xt)) + other terms

Lsimple = Ex₀,t,ε || ε - εθ(xt,t) ||²

KL Divergence

두 확률분포가 얼마나 다른지 측정합니다. 대칭 거리가 아니며 KL(q||p)와 KL(p||q)는 다릅니다.

ELBO

Evidence Lower Bound. 직접 최대화하기 어려운 log evidence의 계산 가능한 하한입니다.

5. DDPM 학습: 긴 영화를 한 장면씩 무작위로 연습

① x₀이미지 선택
+
② t, ε시간·노이즈 선택
→
③ xₜ한 번에 오염
→
④ εθ노이즈 예측
1. x₀~pdata, t~Uniform{1,…,T}, ε~N(0,I)
2. xₜ = √ᾱₜx₀ + √(1-ᾱₜ)ε
3. ε̂ = εθ(xₜ,t)
4. loss = ||ε - ε̂||² → backpropagation
왜 T단계를 모두 돌지 않나? t를 매번 무작위로 뽑으면 각 미니배치가 서로 다른 난이도의 노이즈 제거 문제를 담당합니다. 충분히 반복하면 신경망은 전 시간대를 학습합니다.

6. DDPM 생성: 순수 노이즈에서 T번 복원

xTN(0,I)
→
εθ 예측제거할 노이즈
→
xₜ₋₁조금 더 선명
↻
x₀최종 이미지
xt-1 = 1/√αt · [xt - (1-αt)/√(1-ᾱt) · εθ(xt,t)] + σtz

대괄호는 예측한 노이즈를 제거하는 평균 방향, σₜz는 샘플 다양성을 만드는 새로운 랜덤성입니다. 이 과정을 T→1까지 반복합니다.

DDPM의 약점: 매 단계마다 신경망을 한 번 호출하므로 수백~수천 단계는 VAE·GAN보다 생성이 훨씬 느립니다. 이 병목이 DDIM의 출발점입니다.

7. DDIM: 같은 학습 모델로 계단을 건너뛴다

DDPM 학습 손실은 각 시점의 marginal q(xₜ|x₀)에 의존합니다. DDIM은 이 marginal은 유지하면서 단계 사이의 확률성을 조절할 수 있는 다른 생성 경로를 구성합니다.

DDPM: 모든 계단

확률적 Markov chain · 다양성 높음 · 느림

DDIM: 큰 보폭

η=0이면 결정론적 · step skipping 가능 · 빠름

x̂₀ 예측 = (xₜ - √(1-ᾱₜ) εθ(xₜ,t)) / √ᾱₜ

xt-1 = √ᾱt-1x̂₀ + √(1-ᾱt-1-σₜ²) εθ + σₜz
η=0 → σₜ=0 → 결정론적 DDIM

속도와 품질의 교환

적당한 step 감소: 큰 속도 향상에 비해 품질 저하가 작을 수 있습니다.
과도한 step 감소: 한 번에 너무 멀리 뛰어 복원 오차가 커집니다.

8. 실제로 연결되는 활용

🎨 생성

텍스트 조건을 추가하면 노이즈에서 설명에 맞는 이미지를 복원합니다.

🩹 복원

손상·결측·저해상도 이미지를 관측 조건과 데이터 분포에 맞게 복원합니다.

🔄 편집

이미지를 중간 노이즈 시점으로 보내고 다른 조건으로 역과정을 실행해 속성을 바꿉니다.

2차시로 연결: 1차시는 “제거할 노이즈 ε”를 예측했습니다. 2차시는 같은 복원 방향을 “확률밀도의 기울기 Score”로 다시 표현하고, 이를 연속시간 SDE와 PF-ODE로 일반화합니다.

헷갈리는 개념 바로잡기

🧩 Forward Process도 학습하나요?

아닙니다. βₜ schedule과 Gaussian noise로 우리가 미리 정한 과정입니다. 학습 대상은 이를 되돌리는 εθ 또는 pθ입니다.

🧩 모델이 최종 이미지를 한 번에 예측하나요?

기본 DDPM은 각 시점에서 섞인 노이즈를 예측하고 한 단계씩 복원합니다. 이 작은 결정을 반복해 최종 이미지를 얻습니다.

🧩 ELBO가 곧 최종 MSE인가요?

엄밀히는 ELBO를 분해하고 Gaussian KL을 계산한 뒤 가중치와 상수항을 단순화해 실용적인 noise prediction MSE를 사용합니다.

🧩 DDIM은 별도로 다시 학습해야 하나요?

아닙니다. DDPM 목적함수로 학습한 모델을 재사용하며, 생성 경로와 timestep schedule을 바꿉니다.

🧩 결정론적이면 결과가 항상 하나뿐인가요?

같은 초기 노이즈에서는 같은 결과가 나오지만 초기 노이즈를 다르게 뽑으면 다른 이미지를 생성할 수 있습니다.

🧠 30초 복습

Q1. xₜ에서 원본 신호와 노이즈의 비중을 정하는 누적값은?

ᾱₜ = ∏αₛ입니다.

Q2. DDPM의 실용적인 학습 목표는?

실제 Gaussian noise ε와 예측 noise εθ(xₜ,t)의 MSE입니다.

Q3. DDPM 생성이 느린 직접적인 이유는?

많은 timestep마다 신경망을 반복 호출하기 때문입니다.

Q4. DDIM에서 η=0은 무엇을 의미하나요?

단계 사이 랜덤 항이 사라져 생성 경로가 결정론적이 된다는 뜻입니다.
