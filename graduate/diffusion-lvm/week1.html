STEP 1 · 무엇을 생성하고 어떤 노이즈를 쓰는가

1. 문제 설정과 고차원 Gaussian

PART A · 문제 설정

오늘은 Text-to-Image가 아니라 Unconditional Generation

Conditional

텍스트·클래스·다른 이미지 같은 조건 c를 받아 p(x|c)를 학습합니다. “책을 읽는 곰 인형”처럼 원하는 결과를 지시합니다.

Unconditional

별도 조건 없이 데이터셋의 이미지 분포 pdata(x)를 학습해 그럴듯한 새 이미지를 생성합니다. 이번 차시의 초점입니다.

x₀clean image
q, noise 추가 →
xₜnoisy image
→
xTpure noise
pθ, denoise →
새 x₀generated image

Trajectory(트라젝터리, /trəˈdʒektəri/)는 x₀에서 xT까지 또는 그 반대로 이어지는 전체 경로입니다. Forward는 우리가 정한 확률과정 q, reverse는 학습해야 하는 모델 분포 pθ입니다. Reverse를 “backward propagation”이라고 부르지 않는 이유는 gradient 역전파가 아니라 확산 시간의 방향을 되돌리는 생성과정이기 때문입니다.

PART B · 고차원 Gaussian

이미지는 숫자 하나가 아니라 수십만 차원의 한 점

H×W×C 이미지의 모든 픽셀·채널을 펼치면 하나의 고차원 벡터 x가 됩니다. 1차원 Gaussian에는 평균 μ와 분산 σ²가 있고, 고차원 Gaussian에는 평균벡터 μ와 공분산행렬 Σ가 있습니다.

x ~ 𝒩(μ, Σ)

μ · 뮤

분포의 중심을 나타내는 평균벡터입니다.

Σ · 시그마

각 방향의 퍼짐과 차원 간 함께 변하는 정도를 담는 공분산행렬입니다.

~ · 틸드

“오른쪽 확률분포에서 왼쪽 값을 샘플링한다”라고 읽습니다.

ε ~ 𝒩(0, I)

Isotropic Gaussian(아이소트로픽 가우시안)은 Σ=σ²I처럼 모든 방향의 분산이 같고 비대각 원소가 0인 단순한 Gaussian입니다. 표준 노이즈에서는 σ²=1이므로 Σ=I입니다. 픽셀 차원의 노이즈 성분을 독립이고 동일한 분포(i.i.d.)에서 뽑는다고 가정해 밀도와 샘플링을 쉽게 계산합니다.

정확한 표현: “이미지 픽셀 자체가 독립”이라는 뜻은 아닙니다. 데이터 이미지의 픽셀은 강하게 연관됩니다. 독립 가정은 우리가 추가하는 Gaussian noise ε의 성분에 적용됩니다.
STEP 2 · 사람이 정한 Gaussian 오염 과정

2. Forward Process: 원하는 xₜ를 한 번에 만든다

PART C · Forward Process

한 칸씩 노이즈를 더하는 식

q(xt | xt−1) = 𝒩(√αtxt−1, βtI)
αt = 1 − βt
문장으로 읽기: 이전 이미지 xt−1의 신호를 √αt만큼 남기고, 분산 βt인 Gaussian noise를 더해 xt를 만듭니다.

βₜ · 베타 티

t번째 단계에 새로 추가하는 노이즈의 분산입니다. 사람이 미리 정한 noise schedule의 일부이며 학습 대상이 아닙니다.

αₜ · 알파 티

1−βₜ로 정의한 신호 보존율입니다. 표기를 단순하게 만들기 위한 값입니다.

x₀에서 원하는 xₜ로 한 번에 점프

ᾱt = ∏s=1t αs
xt = √ᾱtx₀ + √(1−ᾱt)ε,   ε~𝒩(0,I)

서로 독립인 Gaussian들의 선형결합은 다시 Gaussian이고 분산은 합쳐집니다. 그래서 x₁,x₂,…를 실제로 차례대로 만들지 않아도 x₀에서 임의의 xₜ를 직접 샘플링할 수 있습니다.

학습 속도의 핵심: 매 학습 iteration마다 1→2→…→t를 실행하지 않습니다. t 하나를 무작위로 뽑고 closed form으로 xₜ 한 장만 즉시 만듭니다.
STEP 3 · q posterior와 pθ의 역할

3. Reverse Process: 정답 역방향을 모델이 배운다

PART D · Reverse Process

알 수 없는 복원 분포를 신경망으로 근사한다

pθ(xt−1|xt) = 𝒩(μθ(xt,t), Σθ(xt,t))

Forward q는 우리가 설계했으므로 압니다. 하지만 순수 노이즈에서 자연스러운 이미지로 돌아오는 실제 분포는 알 수 없습니다. 따라서 신경망 파라미터 θ로 평균과 분산을 근사합니다. 기본 DDPM 설명에서는 분산을 고정하거나 정해진 형태로 두고 평균에 해당하는 정보를 학습하는 관점으로 단순화합니다.

우리가 원하는 것

q(xt−1|xt,x₀)

x₀와 xₜ를 알고 있을 때의 정확한 한 단계 역방향 posterior입니다. Forward Gaussian과 Bayes rule 덕분에 평균 μ̃ₜ와 분산 β̃ₜ를 가진 Gaussian으로 계산할 수 있습니다.

모델이 배우는 것

pθ(xt−1|xt)

생성 시에는 x₀를 모르므로 xₜ와 t만 보고 덜 noisy한 xt−1의 분포를 예측합니다.

GT 역할: 학습 중에는 x₀를 알고 있으므로 계산 가능한 q(xt−1|xt,x₀)가 teacher 역할을 합니다. 모델 pθ가 이 역방향 한 걸음을 닮게 만드는 것이 핵심입니다.
STEP 4 · 긴 수식 유도를 하나의 계단으로

4. Maximum Likelihood → ELBO → Noise MSE

PART E · Maximum Likelihood에서 ELBO까지

직접 풀 수 없는 우도를 계산 가능한 아래 경계로 바꾼다

θ* = argmaxθ 𝔼x₀~qdata[ log pθ(x₀) ]

모델이 실제 training image x₀에 높은 확률을 주도록 θ를 찾고 싶습니다. 그러나 중간 잠재변수 x₁:T의 모든 가능한 경로를 적분해야 하므로 pθ(x₀)는 직접 계산하기 어렵습니다.

pθ(x₀) = ∫ pθ(x₀:T) dx₁:T

교수님이 강조한 ELBO 유도 세 동작

① 1을 곱한다q(x₁:T|x₀) / q(x₁:T|x₀)값은 바꾸지 않고 계산하기 좋은 분포 q를 끼워 넣습니다.
② 기대값으로 바꾼다𝔼q[pθ/q]∫q(z)f(z)dz = 𝔼q[f(z)] 정의를 사용합니다.
③ Jensen을 적용한다log 𝔼[Z] ≥ 𝔼[log Z]log는 concave이므로 log를 기대값 안으로 넣으면 lower bound가 됩니다.
log pθ(x₀) ≥ 𝔼q(x₁:T|x₀)[ log pθ(x₀:T) − log q(x₁:T|x₀) ] = ELBO
문장으로 읽기: 직접 계산하기 어려운 데이터 log-likelihood 대신, 항상 그보다 작거나 같은 계산 가능한 ELBO를 최대화합니다.
Lower bound의 논리: ELBO를 높이면 log-likelihood의 보장되는 하한이 올라갑니다. 둘이 항상 같은 폭으로 움직인다는 뜻은 아니며, 둘의 차이는 variational posterior와 true posterior 사이 KL입니다.
PART F · ELBO를 KL로 분해

복잡한 한 덩어리가 “분포를 닮게 하는 문제”로 바뀐다

DKL(q || p) = 𝔼x~q[ log q(x) − log p(x) ] ≥ 0

KL Divergence(케이엘 다이버전스)는 두 분포의 차이를 측정합니다. 일반적으로 대칭이 아니므로 거리(metric)와 완전히 같지는 않습니다. q를 teacher, pθ를 student로 보면 “teacher가 자주 만드는 영역에서 student의 확률도 높여라”라는 의미입니다.

LT · Prior matching

q(xT|x₀)가 p(xT)=𝒩(0,I)에 가까운지 봅니다. 보통 학습 파라미터와 무관한 항입니다.

＋
Lt−1 · Denoising matching

DKL(q(xt−1|xₜ,x₀) || pθ(xt−1|xₜ)). 핵심 학습 항입니다.

＋
L₀ · Reconstruction

마지막 x₁에서 실제 x₀를 복원할 확률을 높이는 항입니다.

핵심 중간항은 정확히 계산 가능한 true reverse posterior q와 모델의 reverse transition pθ 사이 KL입니다. 둘 다 Gaussian으로 두면 평균과 분산 비교를 닫힌식으로 계산할 수 있습니다.

PART G · Mean Matching → Noise Matching

왜 이미지를 직접 맞히지 않고 노이즈를 맞힐까?

Gaussian KL에서 분산을 고정하면 모델이 학습해야 할 핵심은 두 Gaussian의 평균을 맞추는 일이 됩니다.

|| μ̃t(xₜ,x₀) − μθ(xₜ,t) ||²

그런데 xₜ = √ᾱₜx₀ + √(1−ᾱₜ)ε 관계를 이용해 x₀를 ε로 다시 표현하면 평균 예측을 noise 예측으로 재매개변수화할 수 있습니다.

Lsimple(θ) = 𝔼x₀,t,ε[ || ε − εθ(xₜ,t) ||² ]

ε

우리가 𝒩(0,I)에서 직접 뽑아 x₀에 섞은 실제 노이즈. 따라서 정답을 정확히 압니다.

εθ(xₜ,t)

노이즈 이미지 xₜ와 timestep t를 보고 신경망이 예측한 노이즈입니다.

||·||²

실제 노이즈와 예측 노이즈의 성분별 차이를 제곱해 더하는 L2/MSE 형태입니다.

수업 전체의 결론: 최대우도 → ELBO → KL → Gaussian mean matching이라는 긴 확률론이, 구현 단계에서는 “내가 섞은 노이즈를 모델이 맞히게 한다”는 supervised regression 문제로 바뀝니다.
STEP 5 · 실제 구현 알고리즘

5. DDPM Training: 무작위 한 장면으로 노이즈를 학습한다

PART H · 실제 Training Recipe

모든 timestep을 순서대로 학습하지 않는다

① 데이터x₀ ~ qdata미니배치에서 깨끗한 이미지를 뽑습니다.
② 시간t ~ Uniform({1,…,T})연습할 노이즈 강도를 하나 뽑습니다.
③ 노이즈ε ~ 𝒩(0,I)정답으로 사용할 Gaussian noise를 뽑습니다.
④ 오염xₜ=√ᾱₜx₀+√(1−ᾱₜ)ε중간 단계를 거치지 않고 xₜ를 만듭니다.
⑤ 예측ε̂=εθ(xₜ,t)모델이 섞인 노이즈를 추정합니다.
⑥ 갱신||ε−ε̂||²loss를 backpropagation해 θ를 업데이트합니다.
repeat:
  x₀ ~ data,   t ~ Uniform(1,T),   ε ~ 𝒩(0,I)
  xₜ ← √ᾱₜx₀ + √(1−ᾱₜ)ε
  loss ← ||ε − εθ(xₜ,t)||²
  θ ← optimizer.step(∇θ loss)
Forward와 backpropagation 구분: q의 forward diffusion은 이미지에 노이즈를 넣는 확률과정입니다. 마지막 줄의 backpropagation은 loss gradient로 신경망 파라미터를 갱신하는 학습 알고리즘입니다. 서로 다른 “방향”을 말합니다.

7. DDIM의 핵심은 ‘같은 주변분포, 다른 경로’

유지할 것

학습 손실이 보는 각 시점의 주변분포를 DDPM과 같게 둡니다.

qσ(xt|x₀)=q(xt|x₀)

바꿀 것

시점 사이의 조건부 경로는 결정론적으로 만들 수 있게 새로 정의합니다.

σt=0 → inter-step randomness 제거
x̂₀=(xt-√(1-ᾱt)εθ(xt,t))/√ᾱt

xτᵢ₋₁=√ᾱτᵢ₋₁x̂₀+√(1-ᾱτᵢ₋₁)εθ(xτᵢ,τᵢ)   (σ=0)

Implicit의 뜻: DDIM은 DDPM처럼 모든 역전이 확률을 명시적으로 따르는 Markov chain을 쓰지 않아도, 위 update가 암묵적으로 생성분포를 정합니다. 같은 학습 모델을 재사용하면서 S≪T개의 시점만 고를 수 있습니다.

내 말로 설명하는 최종 답안

모범 답안: DDPM은 사람이 정한 Gaussian forward process로 데이터 x₀에 점진적으로 노이즈를 넣습니다. Gaussian의 닫힘 성질 덕분에 임의의 timestep xₜ를 x₀에서 한 번에 샘플링할 수 있습니다. 직접 최대화하기 어려운 log-likelihood 대신 Jensen 부등식으로 얻은 ELBO를 최대화하고, 이를 true reverse posterior q와 모델 reverse distribution pθ 사이 KL 항으로 분해합니다. 두 분포를 Gaussian으로 두고 분산을 고정하면 mean matching이 되며, 다시 재매개변수화하면 실제로 섞은 ε와 모델이 예측한 εθ(xₜ,t)의 MSE가 됩니다. 그래서 학습은 x₀,t,ε를 뽑아 xₜ를 만들고 노이즈 예측 오차를 역전파하는 단순한 반복입니다.

헷갈리는 개념 바로잡기

🧩 Forward Process도 학습하나요?

아닙니다. βₜ schedule과 Gaussian noise로 우리가 미리 정한 과정입니다. 학습 대상은 이를 되돌리는 εθ 또는 pθ입니다.

🧩 모델이 최종 이미지를 한 번에 예측하나요?

기본 DDPM은 각 시점에서 섞인 노이즈를 예측하고 한 단계씩 복원합니다. 이 작은 결정을 반복해 최종 이미지를 얻습니다.

🧩 ELBO가 곧 최종 MSE인가요?

엄밀히는 ELBO를 분해하고 Gaussian KL을 계산한 뒤 가중치와 상수항을 단순화해 실용적인 noise prediction MSE를 사용합니다.

🧩 DDIM은 별도로 다시 학습해야 하나요?

아닙니다. DDPM 목적함수로 학습한 모델을 재사용하며, 생성 경로와 timestep schedule을 바꿉니다.

🧩 결정론적이면 결과가 항상 하나뿐인가요?

같은 초기 노이즈에서는 같은 결과가 나오지만 초기 노이즈를 다르게 뽑으면 다른 이미지를 생성할 수 있습니다.

🧠 30초 복습

Q1. xₜ에서 원본 신호와 노이즈의 비중을 정하는 누적값은?

ᾱₜ = ∏αₛ입니다.

Q2. DDPM의 실용적인 학습 목표는?

실제 Gaussian noise ε와 예측 noise εθ(xₜ,t)의 MSE입니다.

Q3. DDPM 생성이 느린 직접적인 이유는?

많은 timestep마다 신경망을 반복 호출하기 때문입니다.

Q4. DDIM에서 η=0은 무엇을 의미하나요?

단계 사이 랜덤 항이 사라져 생성 경로가 결정론적이 된다는 뜻입니다.
