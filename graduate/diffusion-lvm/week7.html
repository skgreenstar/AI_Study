1. 먼저 평가축을 분리하자

🖼️ Aesthetics

“좋은 그림인가?”

물리적 개연성·지각 품질·깨끗함·사실성

🎯 Prompt adherence

“지시를 따랐는가?”

객체 재현·개수·글자·위치·속성·스타일

둘은 독립적일 수 있습니다. 아름다운 곰 그림이 나와도 책을 읽지 않는다면 미학 점수는 높고 prompt 충실도는 낮습니다. 안전성·다양성·암기·편향도 별도 평가축입니다.

Elo: 강한 상대를 이긴 승리에 더 큰 의미

EA = 1 / (1 + 10(RB−RA)/400)
R′A = RA + K(SA − EA)

S는 실제 결과(승 1, 무 0.5, 패 0)입니다. 예상보다 뜻밖의 승리일수록 rating이 크게 오릅니다.

사람 평가도 ground truth는 아닙니다. 비싸고 느리며, 피로·문화·전문성·표시 순서에 따라 달라질 수 있으므로 평가자 지침과 품질관리가 필요합니다.

3. Reference-free: 정답 이미지 없이 평가

FID ↓

낮을수록 좋음

실제·생성 이미지 집합을 pretrained encoder의 feature 분포로 바꾸고 평균 위치와 공분산 모양의 차이를 측정합니다.

CLIPScore ↑

높을수록 정렬

prompt embedding과 생성 이미지 embedding의 cosine similarity로 의미 정합성을 봅니다.

PickScore ↑

높을수록 선호

사람의 image preference 데이터로 학습한 CLIP 계열 모델이 prompt 대비 선호도를 예측합니다.

5. MLLM은 이미지를 “말로 이해하는 평가기”가 된다

Image encoder→Visual tokens+Question tokens→Decoder LLM

Flamingo식

이미지 표현을 cross-attention의 Key/Value로 주입합니다.

LLaVA식

이미지 token을 일반 LLM token처럼 문장 안에 함께 넣습니다.

최근 Joint attention

이미지·텍스트 token을 한 decoder에서 함께 처리해 OCR·공간 이해·추론을 확장합니다.

6. TIFA에서 MLLM-as-a-Judge까지

TIFA

Prompt를 “곰이 있는가?”, “책을 읽는가?” 같은 atomic QA로 분해하고 VQA 정답률을 계산합니다.

장점: 어떤 속성에서 실패했는지 해석 가능.

VQAScore

“이 이미지가 prompt를 보여주는가?”라는 질문의 Yes token 확률로 전체 정합성을 평가합니다.

한계: token probability 접근과 여러 MLLM 호출 비용.

VIEScore / Judge

Prompt·이미지·rubric을 주고 evidence, rationale, score를 구조화해 받습니다.

7. 벤치마크는 서로 다른 종목의 경기장

GenEval

객체 조합

객체 1/2개, 개수, 색상, 위치, 색상 귀속을 detection·geometry·color classifier로 판정합니다.

DPG-Bench

긴 Prompt

entity·attribute·relation 질문 graph로 긴 설명의 모든 세부조건을 VQA로 확인합니다.

LongText-Bench

이미지 속 글자

간판·라벨·문서·웹페이지 등의 긴 다국어 text rendering을 OCR 일치로 평가합니다.

GEdit-Bench

이미지 편집

대상 추가/삭제/교체, 배경·색·재질·스타일 변경과 원본 보존을 Judge로 평가합니다.

샘플 이미지는 증거가 아닙니다. 잘 나온 몇 장은 가능성을 보여줄 뿐입니다. 고정 prompt set, 여러 seed, 명시된 sampler와 충분한 표본으로 분포를 평가해야 합니다.

헷갈리는 개념 바로잡기

🧩 FID가 낮으면 프롬프트도 잘 따른다는 뜻인가요?

아닙니다. 실제 이미지 feature 분포와의 거리를 보므로 prompt별 지시 이행은 CLIPScore·TIFA·Judge 등으로 따로 측정해야 합니다.

🧩 CLIPScore 하나면 의미 평가가 끝나나요?

전체 embedding 유사도는 객체 개수·부정·공간관계 같은 세부 실패를 숨길 수 있습니다. Atomic QA나 세부 rubric을 함께 씁니다.

🧩 PSNR이 높은 이미지가 사람이 보기에도 항상 좋은가요?

아닙니다. 픽셀 평균 오차에는 강하지만 지각적 선명도와 의미 보존을 완전히 반영하지 못합니다.

🧩 MLLM Judge는 사람 평가를 완전히 대체하나요?

아닙니다. 전문가 rubric과 human seed로 calibration하고, 일반 사례 자동화 후 경계·실패 사례를 다시 사람이 점검하는 구조가 안전합니다.

🧩 Elo는 절대 품질 점수인가요?

아닙니다. 참여 모델과 대진, 시간에 의존하는 상대 rating입니다. 다른 arena의 Elo 숫자를 직접 비교하면 안 됩니다.

🧩 벤치마크 1등이면 모든 이미지 작업에서 최고인가요?

아닙니다. GenEval, DPG, text rendering, editing은 서로 다른 능력을 측정합니다. 실제 제품 분포를 대표하는 자체 평가셋도 필요합니다.

🧠 30초 복습

Q1. 이미지 생성의 두 핵심 평가축은?

Aesthetics와 Prompt adherence입니다.

Q2. FID는 한 장과 한 장을 비교하나요?

아니요. 실제와 생성 이미지의 feature distribution을 비교합니다.

Q3. SSIM의 세 요소는?

Luminance, Contrast, Structure입니다.

Q4. TIFA가 해석 가능한 이유는?

Prompt를 atomic question으로 쪼개 어떤 조건에서 실패했는지 보여주기 때문입니다.

Q5. Pairwise Judge에서 순서를 무작위화하는 이유는?

A/B의 표시 위치 때문에 생기는 position bias를 줄이기 위해서입니다.
