3. Continuity Equation: 확률 질량은 사라지지 않는다

개별 점은 ODE를 따르고, 전체 분포는 “들어오는 양과 나가는 양”의 차이로 변합니다.

유입이 더 많음
밀도 증가
divergence < 0
확률 Flux = pₜvₜ
유출이 더 많음
밀도 감소
divergence > 0
Continuity Equation
∂pt(x)/∂t + ∇·(pt(x)vt(x)) = 0

시간에 따른 밀도 변화 + 확률 flux의 순유출 = 0
왜 v만 divergence 하지 않나? 같은 속도라도 그 위치에 확률 질량이 거의 없으면 실제로 이동하는 질량도 적습니다. 그래서 속도 v가 아니라 밀도×속도인 probability flux p·v를 봅니다.

4. Conditional Flow Matching: 모르는 전체 길을 쉬운 개별 길로

진짜 marginal velocity uₜ(x)는 알 수 없습니다. 대신 데이터 한 점 x₁을 목적지로 고정하면, Gaussian 경로와 정답 속도를 쉽게 만들 수 있습니다.

x₀Gaussian noise
↘
xₜ(1-t)x₀+tx₁
↗
x₁데이터 샘플
→
uₜ=x₁-x₀정답 velocity
Linear conditional path
xt = (1-t)x₀ + tx₁,   x₀~N(0,I), x₁~pdata
ut(xt|x₁) = d xt/dt = x₁-x₀

CFM loss
LCFM = E || vθ(xt,t) - (x₁-x₀) ||²
①
Dirac 목적지

데이터 한 점으로 가는 쉬운 조건부 경로를 정의

②
조건부 Field

그 경로를 만드는 정답 Velocity를 계산

③
모든 점 혼합

조건부 경로들을 합쳐 marginal path와 field 형성

④
MSE 학습

FM과 CFM의 gradient가 같아 tractable한 회귀 가능

Posterior mean의 의미: 같은 중간 위치 xₜ에 도착할 수 있는 여러 목적지의 조건부 속도를 평균하면 marginal velocity가 됩니다. “지금 여기 있다면 평균적으로 어디로 가야 하는가?”입니다.

5. 학습과 생성 레시피

🎓 Training

1. x₀~N(0,I), x₁~data, t~U(0,1)
2. xₜ=(1-t)x₀+tx₁
3. target=x₁-x₀
4. ||vθ(xₜ,t)-target||² 최소화

경로 전체를 적분하지 않고 임의 시점의 속도만 지도학습합니다.

✨ Inference

1. x₀~N(0,I)
2. dx/dt=vθ(x,t)를 t:0→1 적분
3. x₁을 이미지로 출력

Euler: x←x+Δt·vθ(x,t). 더 정교한 ODE solver도 사용할 수 있습니다.

Continuous Normalizing Flow와 차이: 예전 방식은 학습할 때 ODE를 계속 풀며 likelihood를 계산해 느렸습니다. Flow Matching은 알려진 조건부 Vector target에 대한 회귀로 학습을 단순화합니다.

6. Rectified Flow: 굽은 길을 다시 그려 곧게

무작위로 Noise와 Data를 짝지으면 중간 경로들이 교차하거나 평균화되어 굽을 수 있습니다. 굽은 길은 Euler 근사에 더 많은 step이 필요합니다.

0. 1-Rectified Flow

독립적으로 뽑은 Noise–Data 쌍으로 첫 Flow Model을 학습합니다.

1. Paired Data 생성

같은 Noise를 학습된 ODE에 통과시켜 도착 이미지와 새 쌍을 만듭니다.

2. Reflow

8. 실무에서 왜 Flow Matching을 보나?

⚡ 빠른 생성

경로가 곧을수록 적은 NFE와 단순한 Euler solver로도 품질을 유지하기 쉽습니다.

🎬 이미지·영상 생성

고차원 latent를 연속적인 Vector Field로 운반해 대규모 생성모델의 핵심 패러다임으로 활용합니다.

🔄 도메인 변환

두 데이터 분포 사이의 transport를 학습해 스타일·상태·도메인 전환 문제로 확장할 수 있습니다.

설계 체크: interpolation path, Noise–Data coupling, time sampling, loss weighting, ODE solver와 NFE가 속도·품질을 함께 결정합니다.

헷갈리는 개념 바로잡기

🧩 Flow는 점 하나의 경로인가요?

점 하나의 길은 Trajectory입니다. Flow는 여러 초기점에서 시작한 Trajectory들의 전체 모음입니다.

🧩 Probability Path와 Trajectory는 같은가요?

Trajectory는 한 샘플의 위치 변화이고, Probability Path pₜ는 각 시간에 모든 샘플을 모아 본 분포 변화입니다.

🧩 Flow Matching은 Score를 예측하나요?

기본 Flow Matching은 Velocity Field를 직접 예측합니다. Score 기반 모델과 연결할 수 있지만 학습 target의 의미가 다릅니다.

🧩 Conditional은 텍스트 조건을 뜻하나요?

여기서 Conditional Flow Matching의 condition은 주로 목적 데이터 샘플 x₁에 조건화했다는 수학적 의미입니다. 텍스트 conditioning과는 별개입니다.

🧩 직선 interpolation이면 실제 생성 경로도 항상 직선인가요?

개별 조건부 target은 직선이지만 여러 pairing이 한 위치에서 평균화되면 학습된 marginal field의 경로는 굽을 수 있습니다. Rectified Flow가 이를 개선합니다.

🧠 30초 복습

Q1. 위치와 시간에 따라 이동 방향과 속도를 알려주는 것은?

Vector Field vₜ(x)입니다.

Q2. 선형 경로 xₜ=(1-t)x₀+tx₁의 정답 Velocity는?

x₁-x₀입니다.

Q3. Continuity Equation이 보존하는 것은?

확률 질량입니다. 밀도 변화와 probability flux의 순유출 합이 0입니다.

Q4. Reflow가 생성 속도를 높일 수 있는 이유는?

Trajectory를 더 곧게 만들어 적은 수치 적분 step으로 근사하기 쉬워지기 때문입니다.
