1. LLM은 AI 전체가 아니라 깊숙한 한 갈래

Artificial Intelligence

포함 관계

AI는 지능적인 시스템 전체 개념이며, Machine Learning은 데이터에서 규칙을 학습하는 성공적인 하위 접근입니다.

Deep Learning은 다층 신경망을 이용하는 ML의 하위 분야이고, Transformer는 DL architecture 중 하나입니다.

LLM은 Transformer 계열을 대규모 데이터와 compute로 학습한 언어 모델의 주요 계열입니다.

LLM ⊂ Transformer 계열 ⊂ Deep Learning ⊂ Machine Learning ⊂ AI
수업의 길: Transformer 구조 → LLM 학습·추론 → Agent → Evaluation. 수업 하나로 전문가가 완성되지는 않지만 논문·프로젝트·AI 기사 해석을 위한 출발 지도를 제공합니다.

2. NLP: 인간의 모호한 언어를 기계가 다루는 분야

Natural Language Processing(자연어 처리)은 Python 같은 형식언어가 아니라 사람이 일상에서 쓰는 언어를 이해·변환·생성합니다.

Classification

문장 → label

감정 분석, 의도 탐지, 언어 탐지, topic 분류

예: “이 곰은 정말 귀여워” → 긍정

Token Classification

token → label

품사 태깅, Named Entity Recognition, 구문 분석

예: “서울” → LOCATION

Generation

sequence → sequence

번역, 질의응답, 요약, 자유 텍스트 생성

핵심: 정답 문장이 하나가 아님

Transformer가 분야를 합쳤습니다. 과거에는 NLP·Vision·Speech가 서로 다른 구조를 주로 썼지만, 이제 token sequence와 attention이라는 공통 언어로 이미지·음성·분자까지 연결됩니다.

Accuracy 90%의 함정

긍정 90개·부정 10개에서 전부 긍정이라 하면 accuracy는 90%지만 부정 recall은 0%입니다.

Perplexity 직관

모델이 실제 다음 token을 얼마나 “뜻밖”으로 느끼는지입니다. 낮을수록 덜 놀라지만, 사실성·유용성·안전을 보장하지 않습니다.

PPL = exp(− 평균 log p(xt|x<t))
평가의 본질: 정답 표현이 여러 개인 생성에서는 한 reference와 단어가 얼마나 겹치는지만으로 품질을 단정할 수 없습니다. 그래서 자동 metric·사람 평가·Judge를 목적에 맞게 조합합니다.

4. Tokenization: 문장을 모델의 처리 단위로 자른다

Token은 단어와 항상 같지 않습니다. tokenizer가 정한 vocabulary 항목이며, 문맥에 따라 한 글자·subword·단어·기호가 될 수 있습니다.

Word level

A cute teddy reading

해석은 쉽지만 read·reads·reading이 별도 항목이고 OOV에 약합니다.

Subword level

read ##ing teddy bear

어근과 접사를 재사용해 vocabulary와 sequence 길이의 균형을 잡습니다.

Character/Byte level

r e a d i n g

오타·새 문자열에 강하지만 token 수가 늘어 compute와 문맥 길이를 많이 씁니다.

Word Subword Character/Byte
Vocabulary 큼 중간 작음
Sequence 짧음 중간 김
새 단어·오타 취약 비교적 강함 매우 강함
현대 LLM 드묾 BPE·WordPiece·SentencePiece·byte 계열 조합
OOV(Out-of-Vocabulary): 학습한 단어장에 없는 입력입니다. Subword는 대부분의 새 단어를 기존 조각으로 분해해 OOV를 크게 줄이지만, tokenizer 설계에 따라 unknown token 가능성이 완전히 같지는 않습니다.

5. One-hot은 신분증, Embedding은 의미 지도

One-hot encoding

1 0 0 0 0

token마다 독립된 칸을 줍니다. 서로 다른 두 token의 내적은 항상 0이므로 의미 유사성을 표현하지 못하고 vocabulary만큼 차원이 큽니다.

Learned embedding

.8 .2 −.1 .7 .3

학습된 조밀한 벡터에서는 비슷한 문맥에 등장한 token들이 가까운 방향을 갖도록 만들어집니다.

one_hot(token) × E = embedding(token) ∈ Rd
cosine(u,v) = u·v / (‖u‖‖v‖)
중요한 정정: 단순 내적은 벡터 크기까지 영향을 받습니다. “방향의 유사성”만 비교하려면 보통 cosine similarity 또는 정규화된 embedding의 내적을 사용합니다.

6. Word2Vec: 정답표 없이 문맥으로 의미를 배운다

CBOW

A cute ___ is reading

주변 단어로 가운데 단어를 예측합니다.

↔

Skip-gram

teddy bear → cute, reading

가운데 단어로 주변 단어들을 예측합니다.

Corpus → 자동 생성된 (context, target) pairs → 작은 neural network 학습
학습 후 출력 분류기는 버리고 embedding matrix를 사용

Proxy task

최종 목적 자체는 아니지만 label을 자동으로 얻을 수 있어 대규모 원문을 학습 데이터로 바꿉니다.

Distributional idea

비슷한 문맥에 등장하는 단어는 비슷한 의미를 가진다는 통계적 규칙을 이용합니다.

한계

bank가 은행이든 강둑이든 하나의 고정 벡터입니다. 문맥에 따라 의미가 달라지는 polysemy를 충분히 표현하지 못합니다.

강의 설명 보완: Word2Vec의 대표 학습 목적은 CBOW와 Skip-gram입니다. 현대 GPT의 next-token prediction과 “label 없이 문맥에서 학습한다”는 철학은 이어지지만, 동일한 구조·목적함수는 아닙니다.

PART 1 · 왜 한 학기 수업이 되었나

성공한 하위 분야가 커지면서 독립된 교과목이 된다

과거 머신러닝 한 학기 수업에서 딥러닝은 1~2주 분량의 하위 주제였습니다. 이후 딥러닝 연구와 응용이 빠르게 커지면서 딥러닝 자체가 한 학기 과목이 되었고, 다시 그 안의 Transformer와 LLM이 크게 성장하면서 별도의 한 학기 수업이 필요해졌다는 설명입니다.

AI지능적 시스템이라는 가장 넓은 목표
Machine Learning데이터로 규칙을 학습하는 접근
Deep Learning표현까지 신경망이 함께 학습
Transformer·LLM언어·이미지·음성·과학을 잇는 공통 기반
수강 목표: 이 과목 하나만으로 LLM 전문가가 완성되는 것은 아니지만, LLM 커리어·논문·개인 프로젝트·기술 기사 해석을 시작할 수 있는 공통 언어를 갖추는 것이 목표입니다. 권장 선수지식은 머신러닝·선형대수·딥러닝 기초입니다.
PART 2 · 평가가 왜 어려운가

시험 1등 모델과 실제로 쓰기 좋은 모델이 다를 수 있다

교수님은 강의 당시의 국내 파운데이션 모델 선정 논쟁을 예로 들어, 공개 benchmark 점수가 높더라도 전문가 평가와 실제 사용자 경험에서는 결과가 달라질 수 있다고 강조했습니다. 핵심은 특정 기업의 당락이 아니라 “Benchmark는 능력의 일부만 측정한다”는 점입니다.

Benchmark

정해진 시험과 정답으로 비교하기 쉽지만, 학습 데이터 오염·시험 특화·실사용 분포 차이가 생길 수 있습니다.

User Experience

대화 자연스러움, 지시 이행, 속도, 안정성처럼 실제 사용자가 느끼는 품질입니다.

Expert Review

도메인 정확성·안전·독창성·기술 자립성처럼 단일 시험으로 포착하기 어려운 기준을 봅니다.

좋은 평가 = 자동 Benchmark + Blind Human/Expert + 실제 Task 성공률 + 비용·지연·안전

강의에서 말한 LLM-as-a-Judge는 열린 생성 결과를 더 강한 언어 모델에게 평가시키는 현실적인 방법입니다. 다만 Judge도 틀릴 수 있고 모델 버전이 바뀌며, 표현 순서·말투에 편향될 수 있으므로 고정된 rubric과 human calibration이 필요합니다.

PART 4 · Accuracy 90%가 나쁜 모델일 수 있는 이유

긍정 90개·부정 10개

모델이 모든 문장을 “긍정”으로 예측하면 100개 중 90개를 맞혀 Accuracy는 90%입니다. 그러나 정작 찾고 싶은 부정 문장은 하나도 찾지 못합니다.

예측 긍정예측 부정실제 긍정TP 90FN 0실제 부정FP 10TN 0

관심 class를 “부정”으로 두면

Accuracy = 90/100 = 90%
Precisionnegative = 0
Recallnegative = 0
F1negative = 0

따라서 class imbalance가 있으면 accuracy만 보지 않고 class별 Precision·Recall·F1과 confusion matrix를 함께 봅니다.

PART 5 · 생성 평가지표의 실제 의미

BLEU

주로 번역에서 생성 문장의 n-gram이 reference에 얼마나 정밀하게 겹치는지 봅니다. 같은 의미의 다른 표현은 낮게 평가될 수 있습니다.

ROUGE

주로 요약에서 reference의 중요한 단어·구문을 얼마나 회수했는지 봅니다. 의미·사실성을 직접 이해하는 지표는 아닙니다.

Perplexity

정답 token에 모델이 부여한 확률의 역기하평균입니다. 낮으면 text distribution을 덜 낯설어하지만 좋은 답변과 동일하지 않습니다.

예: “곰이 책을 읽는다” ≈ “책을 읽고 있는 곰”
의미는 비슷하지만 표면 단어 순서가 달라 n-gram 점수는 낮아질 수 있음
홍보 수치 읽기: BLEU·ROUGE가 올랐다는 사실만으로 모델 전체 품질이 좋아졌다고 결론 내리지 말고, 평가 데이터·reference 수·사람 평가·실패 사례를 같이 확인해야 합니다.
PART 6 · Tokenization trade-off를 더 깊게
Wordreading 전체를 한 token으로 저장. 단순하지만 reads·read·reading을 각각 외워야 함.
Subwordread + ing처럼 재사용. 현대 LLM에서 vocabulary와 길이의 현실적 절충.
Characterr·e·a·d…로 분해. 오타에 강하지만 sequence가 길어짐.
Byte모든 입력을 제한된 byte 집합으로 표현. 다국어·희귀문자 OOV를 크게 줄임.

교수님이 든 “번역기가 못 읽게 글자를 일부러 흐트러뜨린 표현” 사례는 fine-grained tokenizer의 강건성을 보여줍니다. 문자가 잘게 분리되면 모델이 이상한 부분을 noise로 보고 남은 패턴에서 원래 표현을 추론할 가능성이 커집니다. 다만 tokenizer만으로 해결되는 것은 아니며, 다양한 노이즈 표현을 본 학습 데이터와 모델의 문맥 추론 능력도 필요합니다.

같은 문장이라도
큰 vocabulary → token 수 ↓, embedding table ↑
작은 vocabulary → token 수 ↑, sequence compute ↑
PART 7 · Word2Vec 학습을 한 단계씩

“의미 벡터를 직접 가르치지 않았는데 왜 의미가 생길까?”

① Corpus“A cute teddy bear reads a book” 같은 label 없는 문장을 모읍니다.
② Pair 생성Skip-gram이면 teddy bear → cute, reads 같은 target pair를 자동 생성합니다.
③ 예측 학습중심 단어에서 주변 단어의 확률을 높이도록 embedding과 output weight를 업데이트합니다.
④ Embedding 사용학습이 끝나면 token→hidden vector를 의미 표현으로 활용합니다.

수많은 문장에서 teddy bear와 plush·cute·soft가 유사한 주변 문맥에 반복 등장하면, 이 단어들을 예측하기 좋은 방향으로 벡터가 가까워집니다. 사람이 “soft와 teddy bear는 비슷하다”는 label을 붙인 것이 아니라 함께 등장하는 통계에서 의미가 만들어집니다.

한계: 고정 Word2Vec은 bank가 “은행”일 때와 “강둑”일 때 같은 벡터를 씁니다. 뒤의 Transformer contextual embedding은 문장 전체를 본 뒤 같은 token에도 서로 다른 표현을 만듭니다.
PART 8 · RNN의 기억이 희미해지는 과정

RNN은 모든 시점에 같은 가중치를 재사용합니다. 그러나 첫 단어의 정보가 마지막까지 가려면 여러 hidden state 변환을 연속으로 통과해야 합니다.

앞 단어
100%→h₂
82%→h₃
64%→h₄
46%→긴 거리
희미함

위 숫자는 개념을 보여주는 비유이지 실제 고정 감소율은 아닙니다. 수학적으로는 역전파 때 Jacobian이 반복 곱해져 값이 1보다 작으면 gradient가 사라지고, 크면 폭주할 수 있습니다.

∂L/∂hearly = ∂L/∂hlate · Πt ∂ht/∂ht−1
반복 곱 → vanishing 또는 exploding gradient

LSTM의 gate는 중요한 정보를 cell state의 비교적 곧은 통로에 보존해 문제를 완화합니다. Attention은 한 걸음 더 나아가 decoder가 필요한 encoder 위치로 직접 연결되게 하여 장거리 정보 경로를 짧게 만듭니다.

헷갈리는 개념 바로잡기

🧩 AI, 머신러닝, 딥러닝, LLM은 같은 말인가요?

아닙니다. 포함 범위가 다릅니다. AI가 가장 넓고, LLM은 딥러닝 기반 언어 모델의 특정 계열입니다.

🧩 Token은 항상 한 단어인가요?

아닙니다. tokenizer에 따라 단어, subword, 문자, byte, 기호가 token이 될 수 있습니다.

🧩 Vocabulary가 작을수록 무조건 좋은가요?

아닙니다. vocabulary가 작으면 embedding table은 줄지만 같은 문장이 더 많은 token으로 늘어 attention 연산과 context를 소비합니다.

🧩 Word2Vec embedding은 문맥마다 달라지나요?

기본 Word2Vec은 단어마다 고정 벡터 하나를 가집니다. Transformer 계열의 contextual embedding은 주변 문장에 따라 token 표현이 달라집니다.

🧩 LSTM이 long-term dependency를 완전히 해결했나요?

gate와 cell state로 크게 완화했지만 sequence를 순서대로 처리하는 긴 경로와 병렬화 한계는 남았습니다.

🧩 Attention이 곧 Transformer인가요?

아닙니다. Attention은 정보를 선택해 가중합하는 mechanism이고, Transformer는 self-attention·FFN·residual·normalization 등을 조합한 architecture입니다.

🧩 BLEU·ROUGE가 높으면 사람이 보기에도 반드시 좋은가요?

아닙니다. reference 표현과 겹치는 정도를 주로 보므로 의미는 맞지만 표현이 다른 답, 사실성, 자연스러움을 놓칠 수 있습니다.

🧠 30초 복습

Q1. 현대 LLM에서 subword tokenization이 널리 쓰이는 이유는?

Vocabulary 크기, sequence 길이, 새 단어 대응 사이의 균형이 좋기 때문입니다.

Q2. One-hot 벡터가 의미 유사도를 표현하기 어려운 이유는?

서로 다른 token 벡터가 모두 직교하여 내적이 0이기 때문입니다.

Q3. Word2Vec의 두 대표 proxy task는?

CBOW와 Skip-gram입니다.

Q4. RNN의 두 핵심 병목은?

Long-term dependency와 순차 처리로 인한 병렬화 제약입니다.

Q5. Attention의 한 문장 직관은?

모든 정보를 하나에 욱여넣지 않고 현재 필요한 원문 위치를 직접 찾아 가중합하는 것입니다.
