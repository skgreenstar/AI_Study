복원 1-A · OOV·서브워드

어휘집 밖의 단어도 읽는 방법

복원 문제어휘집 외 단어 문제(OOV)가 무엇인지 설명하시오. 서브워드(Subword) 토큰화가 단어 단위(Word-level) 토큰화보다 OOV 문제를 줄일 수 있는 이유를 설명하시오.

시험 답안으로 쓰면

어휘집 외 단어 문제(OOV, Out-of-Vocabulary)는 입력된 단어가 토크나이저의 어휘집에 없어 해당 단어를 독립적인 토큰으로 표현하지 못하는 문제이다. 서브워드 토큰화는 단어를 더 작은 하위 단위로 나누므로, 처음 보는 단어도 어휘집에 있는 하위 토큰들의 조합으로 표현할 수 있다. 따라서 단어 단위 토큰화보다 OOV 문제를 줄일 수 있다.

복원 1-B · 원핫·단어 임베딩

번호표에서 의미의 좌표로

복원 문제원핫 인코딩(One-hot Encoding)의 한계 두 가지를 설명하시오. 단어 임베딩(Word Embedding)은 각각의 한계를 어떻게 개선하는지 설명하시오.

복원 2-A · RNN·어텐션·트랜스포머

멀리 있는 정보와 느린 순차 계산

복원 문제번역과 같은 자연어 처리 과제에서 RNN 계열 모델의 한계 두 가지를 설명하시오. 어텐션 메커니즘(Attention Mechanism)과 트랜스포머(Transformer)가 각각의 한계를 어떻게 해결하는지 설명하시오.

시험 답안으로 쓰면

RNN은 정보를 순차적인 은닉 상태로 전달하기 때문에 긴 문장에서 멀리 떨어진 토큰 사이의 관계를 학습하기 어려운 장기 의존성 문제가 있다. 또한 현재 은닉 상태를 계산하려면 이전 은닉 상태가 필요하므로 시퀀스 방향의 병렬 계산이 어렵다. 어텐션은 필요한 입력 위치의 표현을 직접 참조하게 하여 장기 의존성 문제를 완화한다. 트랜스포머는 순환 구조를 제거하여 학습 시 여러 토큰 위치의 계산을 병렬로 수행할 수 있게 한다.

복원 2-B · Q·K·V·멀티헤드

무엇을 찾아 어떤 내용을 가져올까?

복원 문제셀프 어텐션(Self-Attention)의 질의(Query), 키(Key), 값(Value)을 일상적인 비유로 설명하시오. 멀티헤드 어텐션(Multi-head Attention)을 사용하는 이유를 설명하시오.

시험 답안으로 쓰면

도서관에 비유하면 Query는 내가 찾고 싶은 정보, Key는 책을 찾기 위한 색인, Value는 책의 실제 내용이다. 어텐션은 Query와 각 Key의 관련성을 계산하고 이를 가중치로 사용해 Value들을 가중합한다. 멀티헤드 어텐션은 여러 헤드가 서로 다른 관계나 특징을 병렬로 포착하도록 하여 다양한 정보를 함께 표현하기 위해 사용한다.

복원 3-B · MoE·라우팅 붕괴

모든 전문가를 매번 부를 필요는 없다

복원 문제전문가 혼합 모델(MoE)의 기본 아이디어와 장점을 설명하시오. 라우팅 붕괴(Routing Collapse)가 무엇이며 어떻게 완화할 수 있는지 설명하시오.

시험 답안으로 쓰면

전문가 혼합 모델(MoE, Mixture of Experts)은 여러 전문가 네트워크를 두고 입력에 따라 라우터가 사용할 전문가를 결정하는 구조이다. 일부 전문가만 활성화하는 희소 MoE는 전체 전문가를 모두 계산하는 방식보다 입력당 계산량을 줄일 수 있다. 라우팅 붕괴는 라우터가 특정 전문가만 반복적으로 선택해 사용이 편중되는 현상이다. 이를 완화하려면 전문가들이 균형 있게 사용되도록 유도하는 보조 손실을 학습 손실에 추가할 수 있다.

복원 4-A · BERT·MLM·NSP

원문에서 정답을 만드는 사전 학습

복원 문제BERT의 사전 학습 과제인 마스크 언어 모델링(MLM)과 다음 문장 예측(NSP)을 설명하시오. 두 과제가 별도의 수작업 정답 레이블을 요구하지 않는 이유를 설명하시오.

시험 답안으로 쓰면

마스크 언어 모델링(MLM, Masked Language Modeling)은 입력 토큰 일부를 예측 대상으로 선택하고 주변 문맥을 이용해 원래 토큰을 맞히도록 학습하는 과제이다. 다음 문장 예측(NSP, Next Sentence Prediction)은 두 문장이 원문에서 연속된 문장인지 판단하는 이진 분류 과제이다. MLM 정답은 원래 토큰에서, NSP 정답은 원문 순서와 문장 쌍 구성 과정에서 자동으로 얻으므로 사람이 별도로 레이블을 달 필요가 없다.

그림·비교표로 이해하기

BERT란?

트랜스포머 인코더 기반으로 양쪽 문맥을 활용해 토큰 표현을 만드는 모델입니다. 이 문제는 그 표현을 학습시키는 두 가지 과제를 묻습니다.

복원 5-A · 그리디·Top-k·Top-p

확률표에서 다음 토큰 고르기

복원 문제다음 토큰 확률이 Reading 0.40, Sleeping 0.30, Cute 0.15라고 하자. ① 그리디 디코딩의 선택 토큰 ② Top-k(k=2)의 후보 ③ Top-p(p=0.8)의 후보와 선정 과정 ④ 그리디 디코딩만 사용할 때의 문제를 설명하시오. ※ 나머지 토큰 이름과 개별 확률은 녹취에서 확인되지 않습니다.

시험 답안으로 쓰면

그리디 디코딩은 최고 확률 토큰인 Reading을 선택한다. Top-k에서 k=2이면 Reading과 Sleeping을 후보로 남기고 그 안에서 샘플링한다. Top-p에서 p=0.8이면 누적 확률이 0.40 → 0.70 → 0.85가 되므로 Reading, Sleeping, Cute를 후보에 포함한다. 그리디 디코딩만 사용하면 동일한 입력과 계산 조건에서 최고 확률 토큰만 선택하므로 생성 결과의 다양성이 낮다.

복원 5-B · 온도(Temperature)

안정적인 안내와 다양한 아이디어

복원 문제온도(Temperature)가 토큰 확률 분포와 생성 결과에 미치는 영향을 설명하시오. ① 고객센터 챗봇이 환불 규정을 안내할 때 ② 신제품 광고 문구 아이디어를 여러 개 브레인스토밍할 때, 온도를 높게 또는 낮게 설정할지 이유와 함께 설명하시오.

시험 답안으로 쓰면

온도를 낮추면 높은 점수의 토큰에 확률이 더 집중되어 생성 결과의 다양성이 낮아진다. 온도를 높이면 분포가 평탄해져 상대적으로 낮은 점수의 토큰도 선택될 가능성이 커지므로 다양성이 증가한다. 환불 규정 안내는 일관된 전달이 중요하므로 낮은 온도가 적절하고, 광고 문구 브레인스토밍은 다양한 표현과 아이디어가 필요하므로 높은 온도가 적절하다.

설정확률 분포생성 경향시험 사례

높은 온도여러 후보로 확률 분산다양성 증가광고 문구 브레인스토밍
온도를 낮추면 정답이 보장되는 것은 아닙니다. 온도는 선택의 무작위성과 다양성을 조절하며 잘못된 지식을 고치지 않습니다. 교수님은 극한에서 낮은 온도를 델타 함수에, 높은 온도를 균등 분포에 가까워지는 것으로 설명했습니다.

④ 계산과 최소 수식 해부

Top-p: 누적 확률 조건

0.40 + 0.30 = 0.70 < 0.80
0.40 + 0.30 + 0.15 = 0.85 ≥ 0.80

읽는 법: 앞의 두 후보로는 기준에 못 미치므로, 세 번째 Cute까지 넣고 멈춥니다. 기준을 초과한 양을 빼는 계산이 아닙니다.

p(피): 후보 집합이 충족해야 할 누적 확률의 기준. k(케이): Top-k에 남길 후보 개수.

온도(Temperature): 직접 움직여 보기


교수님이 언급한 세 확률과 나머지 확률을 이용한 별도의 이해용 실험입니다. 나머지 0.15는 하나의 가상 후보로 두었습니다. 실제 시험 확률표 전체를 복원한 것은 아닙니다.

온도가 점수를 확률로 바꾸는 방식

P(i) = exp(zᵢ / T) / Σⱼ exp(zⱼ / T)
기호발음·뜻역할
P(i)피 아이 · 후보 i의 확률출력 토큰 선택 확률
i, j아이, 제이 · 후보 인덱스i는 관심 후보, j는 전체 후보 순회
zᵢ지 아이 · 후보 i의 로짓확률 변환 전 모델 점수
T티 · 양수 온도점수 차이를 확대하거나 축소
exp엑스프 · 지수 함수점수를 양수로 변환
Σⱼ시그마 제이 · 모든 후보에 대한 합전체 확률 합을 1로 만드는 분모

문장으로 읽기: 후보의 점수를 온도로 나누고 지수화한 뒤, 모든 후보의 지수화 값의 합으로 나누어 확률을 만듭니다.

왜 필요한가: 낮은 온도에서는 점수 차이가 강조되고, 높은 온도에서는 그 차이가 약해집니다. 수식은 개념 보충용이며 유도는 생략했습니다. 교수님이 이 수식 유도를 출제했다는 뜻은 아닙니다.

단어 전체를 새로 알아야 하는 대신, 어휘집에 있는 하위 토큰들의 조합으로 표현할 수 있기 때문입니다. 분할 단위를 줄이는 것과 벡터 차원을 줄이는 것은 서로 다른 단계입니다.

2. 감성 분석 미세 조정에서도 MLM과 NSP를 그대로 수행할까?

이 문제에서는 감성 레이블을 이용한 분류 과제로 추가 학습합니다. BERT가 만든 [CLS] 출력 벡터에 분류기를 연결해 감성 오차를 줄입니다.

3. 누적 확률이 0.70인데 다음 후보를 넣으면 0.85가 된다. p=0.8이라면?

다음 후보까지 포함합니다. Top-p는 누적 확률이 기준 이상이 되는 최소 후보 집합을 고르므로 0.70에서 중단하면 안 됩니다.
