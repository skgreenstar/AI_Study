추론 모델

"답하기 전에 생각하게 하면 더 잘 푼다"는 3장의 Chain of Thought를 훈련 단계에서 대규모로 밀어붙인 것이 추론 모델입니다. 사람이 풀이를 써 주지 않고도 생각하는 법을 가르치는 방법을 봅니다.

풀이를 베끼지 않고 배우기

채점만 해 주는 코치

코치가 모범 풀이를 주지 않습니다. 학생은 같은 문제를 여러 방식으로 풀어 보고, 코치는 맞았는지 틀렸는지만 알려 줍니다. 학생은 "어떤 풀이 습관이 정답으로 이어지는지"를 스스로 터득합니다. 사람이 쓴 풀이에 갇히지 않는다는 장점도 있습니다.

GRPO

같은 조 안에서의 상대 평가

한 문제에 답안 여러 개를 써 보고, 그 조의 평균보다 잘했으면 칭찬, 못했으면 꾸중합니다. 문제가 쉬워 다 맞으면 아무도 칭찬받지 않고, 어려워 다 틀리면 아무도 혼나지 않습니다. "이 문제에서 평소 실력"을 따로 예측하는 심판(가치 모델)이 필요 없습니다.

한계. 모두 맞거나 모두 틀린 문제에서는 배울 신호가 0입니다. 그리고 채점이 자동으로 되는 과목(수학, 코딩)에서만 통합니다.

최소 수식 해부

수식 1

GRPO의 어드밴티지

Ai = ( ri − mean(r1, …, rG) ) / std(r1, …, rG)
ri알 아이조 안 i번째 답의 보상G지한 질문에 만든 답의 수(조 크기)Ai에이 아이조 평균 대비 얼마나 잘했나
숫자 예제. 한 문제에 답 4개, 보상 [1, 0, 0, 1].
평균 0.5, 표준편차 0.5 → 어드밴티지 [+1, −1, −1, +1].
보상이 [1, 1, 1, 1]이면 평균 1, 차이 전부 0 → 신호 없음.
문장으로 읽기: 맞힌 답을 만든 토큰들의 확률은 올리고, 틀린 답을 만든 토큰들의 확률은 내린다.
수식 2

GRPO 목적 함수의 뼈대

(1/G) Σi (1/|oi|) Σt min( ρi,t Ai, clip(ρi,t, 1−ε, 1+ε) Ai ) − β KL(π ‖ πref)
|oi|오 아이의 길이i번째 답의 토큰 수ρi,t로t번째 토큰에서 새/옛 정책 확률 비β KL베타 케이엘기준 모델에서 멀어지면 감점
문장으로 읽기: PPO-Clip과 같은 모양인데, 어드밴티지는 조 평균으로 구하고 KL은 따로 뺀다.
길이 문제의 출처: 1/|oi|. 긴 답일수록 토큰 하나가 받는 신호가 작아진다. DAPO·Dr. GRPO는 이 나눗셈을 바꾼다.
수식 3

Pass@k

Pass@k = 1 − (1 − p)k   (시도가 독립일 때)
p피한 번 시도해 성공할 확률k케이시도 횟수(1−p)k전부 실패k번 모두 실패할 확률
숫자 예제. p = 0.3 → Pass@1 = 0.30, Pass@5 = 1 − 0.7⁵ ≈ 0.83, Pass@10 ≈ 0.97.
한 번에 30%밖에 못 푸는 모델도 5번 기회를 주면 83%가 된다. Pass@k만 보고 "잘한다"고 판단하면 안 되는 이유. 실제 평가에서는 n번 생성해 그중 c번 성공한 표본으로 추정한다. 8장의 Pass^k(전부 성공)와 대비해 보자.
수식 4

R1 보상의 조립

r = r형식 + r정확도 (+ r언어 일관성)
항확인하는 것방법
형식<think> 구분자가 제대로 있는가규칙(문자열 검사)
정확도풀이가 맞는가코드: 테스트 실행 / 수학: 정답 비교
언어 일관성질문과 같은 언어로 생각·답했는가R1의 ③단계에서 추가
문장으로 읽기: 보상은 여러 규칙의 합이다. 무엇을 더하느냐가 곧 모델에게 바라는 행동의 명세서다.

자주 하는 오해

❌ "추론 모델은 구조가 다른 새 신경망이다."
✅ 같은 디코더 전용 Transformer입니다. 달라진 것은 학습 방법과 출력 형식(생각을 먼저 쓰고 답을 씀)입니다.
❌ "화면에 보이는 생각 요약이 모델의 실제 추론 전체다."
✅ 대개 요약본입니다. 전체 추론 사슬은 숨겨지지만 토큰 요금에는 포함됩니다.
❌ "GRPO는 PPO와 완전히 다른 알고리즘이다."
✅ 확률 비율과 클리핑은 같습니다. 다른 점은 어드밴티지를 가치 모델 대신 조 평균으로 구하는 것과 KL 항의 위치입니다.
❌ "오래 생각할수록 항상 좋다."
✅ 쉬운 질문에 긴 추론은 낭비이고, 길어지는 것 자체가 학습 방식의 부작용일 수 있습니다. 그래서 생각 예산을 조절합니다.

확인 퀴즈 3문항

답을 열기 전에 소리 내어 답해 봅니다.

Q1. 한 문제에 답 4개를 만들었더니 보상이 [1, 0, 0, 0]이었다. 맞힌 답과 틀린 답의 어드밴티지 부호는? 모두 0이었다면?
평균이 0.25이므로 맞힌 답은 양수(+0.75를 표준편차로 나눈 값), 틀린 답 셋은 음수(−0.25를 표준편차로 나눈 값)입니다. 모두 0이면 평균도 0이라 차이가 전부 0이고 학습 신호가 없습니다.
Q2. 추론 능력을 가르칠 때 사람이 쓴 풀이로 SFT하지 않고 RL을 택한 이유 세 가지는?
추론 사슬을 대량으로 손으로 쓰기가 비현실적이고, 모델을 사람이 쓴 풀이 방식에 묶어 두고 싶지 않으며, "문제를 풀었는가"라는 자동 검증 가능한 보상이 자연스럽게 존재하기 때문입니다.
Q3. R1-Zero가 이미 추론을 잘했는데도 R1은 왜 SFT 단계를 두 번이나 넣었을까?
R1-Zero의 추론 사슬은 형식과 가독성에 문제가 있었습니다. 다듬은 CoT로 먼저 SFT해 읽기 좋은 추론 형식을 잡고, 나중의 대규모 SFT로 추론 외의 일반 대화 능력까지 갖추게 했습니다.
