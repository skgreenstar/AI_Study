1. Reasoning Model은 무엇이 다른가?

일반 LLM 위에 별도 마법 상자를 붙이는 것이 아니라, 답하기 전 계산을 더 쓰고 검증 가능한 결과로 행동을 다듬는 학습 패러다임입니다.

⚡ 즉답형

질문 → 답익숙한 패턴과 지식을 빠르게 재현

요약·문체 변환·아이디어 생성처럼 열린 과제에 강합니다.

🌳 추론형

질문 → 탐색 → 확인 → 답중간 가설을 세우고 수정

수학, 코딩, 논리처럼 정답을 검사할 수 있는 과제에 특히 유리합니다.

🚧 같지 않은 것

추론 ≠ 최신 지식
추론 ≠ 검색
추론 ≠ 실제 행동

검색 도구와 실행 권한이 있어야 에이전트처럼 외부 세계에 작용합니다.

주의: 화면에 보이는 설명은 이해를 돕는 요약일 수 있으며, 모델 내부 계산과 완전히 일치한다고 보장할 수 없습니다. 좋은 시스템은 “그럴듯한 독백”보다 검증 가능한 근거와 결과를 보여줍니다.

헷갈리는 지점 바로잡기

🧩 CoT를 길게 쓰면 무조건 추론이 좋아지나요?

아닙니다. 유용한 탐색은 늘 수 있지만 반복, 자기모순, 과잉 사고도 늘 수 있습니다. 길이보다 검증 결과와 효율이 중요합니다.

🧩 GRPO는 PPO와 완전히 다른가요?

둘 다 정책 최적화 계열이며 정책 변화 제한 같은 아이디어를 공유합니다. 핵심 차이는 advantage의 기준선을 별도 가치 모델 대신 같은 문제의 응답 그룹에서 얻는다는 점입니다.

🧩 보상을 자동으로 주면 안전한가요?

아닙니다. 모델이 검증기의 허점을 공략하는 reward hacking이 생길 수 있습니다. 숨은 테스트, 다양한 검증기, 사람 평가를 함께 설계해야 합니다.

🧩 추론 모델이면 사실 오류도 사라지나요?

아닙니다. 잘못된 지식에서 논리적으로 전개할 수도 있습니다. 최신·외부 사실은 검색과 출처 검증이 별도로 필요합니다.

🧠 30초 복습

Q1. 한 문제에서 8개 응답을 만들고 하나라도 정답인지 보는 지표는?

Pass@8. 단발 성능은 Pass@1입니다.

Q2. 보상이 [0, 1, 1, 0]이면 그룹 평균은?

0.5. 정답 응답은 평균 대비 +0.5, 오답은 −0.5의 상대적 advantage를 갖습니다.

Q3. R1-Zero에 추가되어 R1의 가독성과 일반 능력을 보강한 것은?

Cold-start 추론 SFT, 대규모 추론·일반 SFT, all-scenario RL입니다.
