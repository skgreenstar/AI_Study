🔦 Attention은 ‘관련성 스포트라이트’

먼 단어도 직접 연결

예: “고양이가 소파에 앉았다. 그것은 졸렸다.”

그것은고양이소파앉았다졸렸다

‘그것은’이 무엇인지 해석할 때 모델은 관련성이 높은 ‘고양이’에 더 강한 가중치를 줍니다.

수식은 ‘질문·열쇠·내용’으로 보기

i
Query /ˈkwɪri/Key /kiː/Value /ˈvæljuː/퀴어리 · 키 · 밸류
한글 뜻: 질문 · 검색 표지 · 가져올 내용도서관에서 질문(Q)으로 색인(K)을 찾고 관련 책의 본문(V)을 가져오는 과정과 같습니다.
Query→Key 비교→관심도→Value 전달
Attention(Q,K,V) = softmax(QKᵀ / √dₖ)V
i
Softmax/ˈsɔːftmæks/소프트맥스
한글 뜻: 점수를 확률형 비율로 변환하는 함수여러 점수를 모두 합해 1이 되는 양수 비율로 바꿔, 무엇을 얼마나 참고할지 정합니다.
점수→지수화→합으로 나눔→관심 비율
Q
Query · 무엇을 찾지?현재 토큰이 던지는 질문
K
Key · 나와 관련 있나?각 토큰을 찾기 위한 표지
V
Value · 가져올 내용관련성이 높을 때 실제로 섞을 정보
