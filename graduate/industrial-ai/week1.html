SLP는 “선 하나”, MLP는 “여러 경계를 조합”

① Single-layer Perceptron (SLP) (단층 퍼셉트론)

AND / OR ✅
0과 1 사이에 직선 하나를 그으면 구분된다.
→ linearly separable (선형 분리 가능)

AND

핵심: 1인 점 하나를 나머지 0과 직선 하나로 분리 가능.

OR

핵심: 0인 점 하나와 나머지 1들을 직선 하나로 분리 가능.

② 그런데 XOR은?

XOR ❌
어느 방향으로 직선을 그어도 0/1이 함께 남는다.
→ not linearly separable (선형 분리 불가능)

한 문장으로 머릿속에 박기:
SLP = 자 하나 들고 직선 한 번 그어서 나누는 모델.
MLP = Hidden layer에서 여러 판단을 만든 뒤 조합해서 더 복잡한 경계를 만드는 모델.
그래서 PDF가 MLP를 “Solution to nonlinearly separable problem”으로 연결하는 거야.
🎯 시험 포인트: “Single-layer Perceptron (SLP) (단층 퍼셉트론)은 linear classifier (선형 분류기)이다. AND와 OR은 linearly separable (선형 분리 가능)하지만 XOR은 not linearly separable (선형 분리 불가능)이므로 SLP로 해결할 수 없다. 이후 Multi-layer Perceptron (MLP) (다층 퍼셉트론)은 nonlinearly separable problem (비선형 분리 문제)을 해결할 수 있는 구조로 제시된다.”
주의: y=ax+b로 안 된다는 표현은 PDF 원문 용어가 아니라 이해를 위한 비유입니다. 답안에서는 linear classifier (선형 분류기) / linearly separable (선형 분리 가능) / not linearly separable (선형 분리 불가능)을 우선 사용하세요.

5. Transformer 이후 무엇이 바뀌었나?

Before Transformer

RNN / LSTM — 왜 등장했고 무엇이 달랐나?

RNN (순환 신경망) = “앞에서 읽은 내용을 메모해서 다음 단어로 넘긴다”

핵심: 현재 단어만 보는 게 아니라 이전 hidden state (은닉 상태)를 함께 받아 과거 정보를 이어간다. 하지만 문장이 아주 길어지면 초반 정보가 약해질 수 있다.

LSTM (Long Short-Term Memory) = “중요한 기억은 오래 들고 가고, 필요 없는 것은 버린다”

💡 기억법: RNN은 메모 한 장을 계속 넘기는 사람, LSTM은 그 메모에 지우개(Forget) + 기록(Input) + 꺼내보기(Output) 기능을 붙인 사람. 그래서 장기 의존성 문제를 완화한다.
하지만 둘 다: token을 시간 순서대로 처리하는 sequential computation (순차 계산) 구조이므로 대규모 병렬 학습에는 병목이 생긴다. 이 지점이 Transformer로 이어지는 연결고리.

💡 머릿속 장면: RNN/LSTM은 전달 릴레이, Transformer는 회의실. 회의실에서는 멀리 앉은 사람에게도 바로 질문할 수 있다. 그래서 PDF가 강조하는 better parallelism + easier long-range relationships로 연결된다.
🎯 시험 포인트: Transformer는 recurrence 대신 attention을 중심으로 sequence를 처리하며, Self-attention lets each token directly look at every other token. 그 결과 RNN/LSTM보다 병렬 처리와 장거리 관계 모델링에 유리하다.
② BERT — Learn by Filling in the Blank

BERT는 “빈칸 탐정”: 왼쪽 + 오른쪽 문맥을 모두 보고 정답을 추론

왜 Bidirectional (양방향)? 빈칸 왼쪽의 “Paris is the”뿐 아니라 오른쪽의 “of France”도 함께 사용하기 때문. 그래서 문장의 의미를 이해·표현하는 데 강한 방식으로 생각하면 직관적이야.
헷갈리지 않기: 여기서 BERT의 핵심 그림은 “문장을 왼쪽→오른쪽으로 계속 생성”이 아니라 가려진 token을 주변 문맥으로 맞히는 것.

③ GPT — Next-token Prediction

GPT는 “이어쓰기 작가”: 지금까지 나온 말만 보고 다음 token을 하나씩 생성

💡 기억법: GPT = 휴대폰 키보드의 “다음 단어 자동완성”을 엄청나게 크게 확장한 것이라고 생각하면 좋아. 기본 학습 목표는 단순한 Next-token prediction인데, 모델·데이터·compute를 크게 키우면서 다양한 능력이 나타난다는 것이 강의의 흐름.

⑤ 자율주행 / Vision System

실무 관점 연결: 산업 AI는 결국 Model + Data + System + Domain Knowledge (도메인 지식) + Deployment (배포)의 결합입니다. 1주차 후반 사례들은 이후 수업의 시계열, 이상탐지, MLOps, 산업용 비전으로 자연스럽게 이어집니다.

12. 셀프 퀴즈 — 눌러서 정답 확인

Q1. Deep Learning (딥러닝)은 AI와 어떤 관계인가?

Deep Learning (딥러닝)은 Machine Learning (머신러닝)의 하위 범주이고, Machine Learning (머신러닝)은 Artificial Intelligence (인공지능)의 하위 범주입니다.

Q2. XOR이 단층 퍼셉트론으로 어려운 이유는?

XOR의 클래스 배치가 하나의 직선(초평면)으로 분리되지 않는 비선형 분리 문제이기 때문입니다.

Q3. Transformer의 핵심 아이디어를 한 문장으로?

Recurrence 대신 self-attention을 중심으로 시퀀스를 모델링하여 병렬 처리와 장거리 관계 모델링을 쉽게 만든 구조입니다.

Q4. In-context learning이 왜 역사적으로 중요한가?

테스트 시 모델 파라미터를 다시 학습하지 않아도 프롬프트의 지시와 예시를 통해 새로운 태스크를 수행할 수 있게 되었기 때문입니다.

Q5. Workflow (워크플로·정해진 작업 흐름)와 Agent (에이전트·자율 실행 주체)의 가장 중요한 차이는?

Workflow (워크플로·정해진 작업 흐름)는 다음 단계가 코드에 의해 미리 정해지는 반면, Agent (에이전트·자율 실행 주체)는 중간 결과에 따라 LLM이 다음 단계를 동적으로 선택합니다.

Q6. 산업 AI에서 모델 성능만 좋으면 충분할까?

강의 후반 사례들의 메시지는 그렇지 않다는 것입니다. 데이터, 경량화, 하드웨어, 공정/도메인 이해, 시스템 구현, 배포와 운영까지 연결되어야 산업적 가치가 생깁니다.

13. 30초 복습 카드

AI = Perceive → Learn/Reason → Act/Generate

AI 발전 = Data × Compute × Algorithms

역사 = Perceptron → MLP → Deep Learning (딥러닝) → Transformer → LLM → Multimodal (멀티모달·다중양식) → Agentic AI (에이전트형 AI)

산업AI = Model + Data + System + Domain + Deployment (배포)
