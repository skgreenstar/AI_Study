01. 시계열이 일반 표 데이터와 다른 이유

시계열(time series)은 시간 순서로 관측한 값의 열 X₁, X₂, …, Xₜ입니다. 시점 간 순서와 간격이 의미가 있고, 이전 값이 다음 값과 관련될 수 있습니다. 임의 셔플을 하면 정보 누출이나 시계열 의존성 손실이 발생할 수 있습니다.

Xₜ = f(Xₜ₋₁, Xₜ₋₂, …) + εₜ

εₜ는 이전 값만으로 설명하지 못한 변동입니다. 제조 설비의 온도·압력·유량·순도 예측에 이 관점을 적용합니다.

Univariate

하나의 값이 시간에 따라 변화: 예) 설비 온도 하나. 입력에 과거 시점 여러 개를 사용해도 단변량일 수 있습니다.

Multivariate

온도·압력·유량 등 여러 변수의 시간적 변화를 함께 관측합니다. 변수 간 상호작용도 학습 대상입니다.

시간 패턴 네 가지

패턴뜻예시
Trend장기 증가·감소설비 노후화에 따른 진동 증가
Seasonality고정 주기의 반복하루 단위 전력 수요
Cycle반복되지만 고정 주기가 불명확경기 변동
Irregular설명되지 않는 변동측정 잡음·돌발 이벤트
자료 연결 · ETT(변압기 온도 관련 시계열)와 UCR 시계열 분류 데이터가 강의에 등장합니다. ETT 표는 날짜 열과 7개 수치 변수를 포함하는 예시입니다.

02. 정상성(Stationarity): 시간에 따라 통계적 성질이 안정적인가?

약정상성(weak stationarity)은 평균과 분산이 시간에 의존하지 않고, 두 시점의 공분산이 절대 시점이 아니라 시차(lag)에만 의존하는 성질입니다.

E[Xₜ] = μ
Var(Xₜ) = σ² < ∞
Cov(Xₜ, Xₜ₋ₖ) = γ(k)

강정상성(strict stationarity)은 모든 유한 차원 결합분포가 시간 이동에도 동일한 더 강한 정의입니다. 평균·분산이 유한한 강정상 과정은 약정상이지만 역은 일반적으로 성립하지 않습니다.

정상성에 가까운 신호

평균과 변동 폭이 시간에 따라 대체로 일정합니다.

추세가 있는 비정상 신호

시간에 따라 평균 수준이 올라가므로 일반적으로 비정상입니다.

시험 함정 · 정규화(normalization)와 정상성(stationarity)은 다릅니다. 전체 데이터를 같은 범위로 스케일링했다고 시간에 따른 평균·공분산 변화가 사라지는 것은 아닙니다.

03. 자기상관함수(ACF)와 백색잡음

자기공분산 γ(k)를 0시차 분산 γ(0)으로 나눈 값이 자기상관 ρ(k)입니다. 시간차 k만큼 떨어진 두 관측값의 선형 관계를 나타냅니다.

γ(k) = Cov(Xₜ, Xₜ₋ₖ)
ρ(k) = γ(k) / γ(0)
ρ(0) = 1,   −1 ≤ ρ(k) ≤ 1

양수는 같은 방향, 음수는 반대 방향의 선형 관련성을 의미합니다. ACF가 높다고 인과관계가 입증되는 것은 아닙니다.

지속성이 큰 신호의 ACF

백색잡음(White noise)

평균 0, 일정한 유한 분산, 서로 다른 시차에서 공분산 0인 잡음입니다.

E[εₜ]=0
Var(εₜ)=σ²
Cov(εₜ,εₛ)=0 (t≠s)

백색잡음은 반드시 정규분포일 필요가 없으며, 무상관은 독립보다 약한 조건입니다.

핵심 연결 · 모델링 후 잔차에 의미 있는 자기상관이 남아 있다면 모델이 시간 구조를 충분히 설명하지 못했을 수 있습니다.

04. 평활(Smoothing): 잡음을 줄이고 패턴을 드러낸다

단순 이동평균(Simple Moving Average)

SMAₜ = (Xₜ + Xₜ₋₁ + … + Xₜ₋ₘ₊₁) / m

최근 m개 관측값을 동일 가중치로 평균합니다. m이 커질수록 매끄러워지지만 급격한 변화에 대한 반응이 느려집니다.

가중 이동평균(Weighted Moving Average)

WMAₜ = Σᵢ wᵢ Xₜ₋ᵢ   (Σᵢ wᵢ=1)

최근 관측값에 더 큰 가중치를 줄 수 있습니다.

지수평활(Exponential Smoothing)

Sₜ = α Xₜ + (1−α)Sₜ₋₁,   0<α≤1

α가 클수록 최신 값에 민감하고, 작을수록 과거 정보를 더 오래 유지합니다. 반복 전개하면 과거 값의 가중치가 기하급수적으로 감소합니다.

🎛️ 직접 실험: α를 바꾸면?

주의 · 이동평균이라는 말은 데이터 평활용 이동평균과 후속 단원의 MA(q) 확률모형에서 의미가 다릅니다. 후자는 관측값이 아니라 현재·과거의 오차항을 조합합니다.

05. 시계열 분해(Decomposition)

관측값을 추세 T, 계절 S, 잔차 R로 나눠 각 성분의 역할을 살펴봅니다.

가법 분해

Xₜ = Tₜ + Sₜ + Rₜ

계절 진폭이 수준과 무관하게 비교적 일정할 때 적합합니다.

승법 분해

Xₜ = Tₜ × Sₜ × Rₜ

수준이 커질수록 계절 진폭도 커지는 양상에 사용합니다. 로그를 취하면 가법 구조로 바꿀 수 있습니다(양수 데이터).

분해의 일반적인 순서는 추세 추정 → 추세 제거 → 같은 계절 위치의 평균으로 계절 성분 추정 → 잔차 계산입니다. 가법 계절 성분은 한 주기 합이 0이 되도록 중심화할 수 있습니다.

CO₂ 월별 자료 사례

강의에서는 CO₂ 관측치를 월별로 재표본화하여 추세와 계절 변동을 분리하는 예시를 다룹니다. 이동평균의 창 크기, 결측 보간, 경계 구간의 처리 방식에 따라 결과가 달라질 수 있습니다.

잔차 Rₜ = Xₜ − Tₜ − Sₜ

가법 분해에서 미래 추세와 계절 성분을 각각 예측했다면 최종 예측은 두 성분을 다시 더하는 방식으로 복원할 수 있습니다.

06. 자기회귀 AR(p): 과거 값으로 현재를 설명한다

AR은 AutoRegressive의 약자입니다. 현재 값이 이전 p개 값의 선형 결합과 오차로 표현된다는 가정입니다.

Xₜ = c + φ₁Xₜ₋₁ + … + φₚXₜ₋ₚ + εₜ
기호의미
p사용하는 과거 시차 개수. 모델 차수이자 하이퍼파라미터
c상수항(절편)
φ₁…φₚ학습 데이터에서 추정하는 계수(파라미터)
εₜ예측식이 설명하지 못하는 혁신/오차항

예를 들어 AR(2)는 바로 이전 값과 두 시점 이전 값을 사용합니다.

Xₜ = c + φ₁Xₜ₋₁ + φ₂Xₜ₋₂ + εₜ

AR(1) 정상성의 대표 조건

Xₜ = c + φXₜ₋₁ + εₜ
|φ| < 1

백색잡음과 표준 가정하에 |φ|<1이면 안정적인 정상해가 존재합니다.

μ = c/(1−φ)
Var(Xₜ)=σ²/(1−φ²)

직접 계산해 보기

AR(2)에서 c=1, φ₁=0.6, φ₂=0.2이고 이전 값이 Xₜ₋₁=10, Xₜ₋₂=5라면?

X̂ₜ = 1 + 0.6×10 + 0.2×5 = 8

미래 실제 관측은 εₜ의 영향으로 예측값과 다를 수 있습니다.

교수님 설명의 요점 · p는 어떤 과거까지 볼지 정하는 하이퍼파라미터이고, φ 계수는 실제 데이터에서 학습합니다. AR은 과거 관측을 예측에 사용하며, 평활법은 과거 관측을 주로 요약·매끄럽게 만든다는 목적상의 차이가 있습니다.

서술형 ① 정상성을 수식으로 정의하시오.

약정상성: E[Xₜ]=μ, Var(Xₜ)=σ²<∞, Cov(Xₜ,Xₜ₋ₖ)=γ(k). 즉 평균과 분산이 일정하고 자기공분산은 시차 k만의 함수입니다.

서술형 ② 지수평활에서 α의 역할을 설명하시오.

α는 현재 관측값의 가중치입니다. 클수록 새 변화에 빠르게 반응하지만 잡음에도 민감하며, 작을수록 평활 효과가 커지고 반응이 느려집니다.

서술형 ③ AR(p)의 파라미터와 하이퍼파라미터를 구분하시오.

차수 p는 사전에 선택하거나 검증으로 결정하는 하이퍼파라미터이고, c 및 φᵢ는 데이터를 통해 추정하는 모델 파라미터입니다.

08. 다음 진도 예습: MA·ARMA·PACF·ARIMA

아래는 강의 슬라이드 제목과 이어지는 학습을 위한 추가 배경지식입니다. 이번 수업에서 슬라이드 32까지 실제 설명한 범위와 구분하세요.

MA(q) · Moving Average 확률모형

Xₜ = μ + εₜ + θ₁εₜ₋₁ + … + θq εₜ₋q

현재와 과거 오차항의 결합입니다. 평활용 이동평균과 구분해야 합니다.

ARMA(p,q)

Xₜ = c + ΣφᵢXₜ₋ᵢ + εₜ + Σθⱼεₜ₋ⱼ

AR의 과거 관측값과 MA의 과거 오차항을 함께 사용합니다.

PACF와 invertibility

PACF는 중간 시차들의 선형 영향을 통제한 부분 자기상관입니다. MA 모형의 invertibility(가역성)는 오차항을 관측 시계열의 안정적인 표현으로 복원할 수 있는지와 관련됩니다.

ARIMA

비정상 시계열을 차분하여 ARMA 계열 모형을 적용하는 확장입니다. 차분 횟수를 d로 나타냅니다.
