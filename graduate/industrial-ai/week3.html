선택 기준 한 문장
정답 규칙이 “설명하기보다 보여주기 쉬울 때” 머신러닝의 가치가 큽니다. 단, 미래가 과거와 너무 다르거나 한 번의 오류도 허용할 수 없고 사람이 확인할 수도 없다면 적합성을 다시 검토해야 합니다.

🎙️ 교수님 설명으로 잡는 머신러닝의 본질

머신러닝은 결국 “곱하고 더할 숫자”를 데이터로 찾는 과정

입력 숫자들을 어떤 비율로 곱하고 더해야 원하는 출력이 나오는지 모델이 학습합니다. 딥러닝이 GPU에서 빠른 이유도 거대한 행렬의 곱셈과 덧셈을 병렬로 반복하기 때문입니다. 다만 이것은 계산의 모습이고, 학습의 목적은 새 데이터에도 통하는 관계를 찾는 것입니다.

🧭 데이터에 무엇이 들어 있나?

🏷️ Supervised Learning

지도학습 — 입력 x와 정답 y를 함께 보여주고, 새 입력의 정답을 예측하도록 학습합니다.

숫자 예측은 회귀, 범주 예측은 분류입니다.

🧩 Unsupervised Learning

비지도학습 — 정답 없이 입력만 보고 그룹·방향·압축 표현·이상점을 찾습니다.

K-means 군집화, PCA 차원축소가 대표적입니다.

🎮 Reinforcement Learning

강화학습 — 환경에서 행동하고 늦게 받는 보상을 바탕으로 장기 보상이 커지는 정책을 배웁니다.

로봇 제어·공정 스케줄링처럼 연속 의사결정에 씁니다.

📈 Regression · 회귀

온도, 가격, 배터리 잔여 수명처럼 연속적인 숫자를 예측합니다.

🗂️ Classification · 분류

정상/불량, 불량 종류처럼 이산적인 범주를 예측합니다. 회귀 결과에 문턱값을 적용해 분류할 수도 있지만 그 문턱값은 설계자가 책임져야 합니다.

📏 교수님이 그린 직선의 의미

회귀: ŷ = wx + b

키 x와 발 크기 y처럼 연속적인 관계를 가장 잘 설명하는 직선을 찾습니다. w는 직선의 기울기, b는 위아래 위치를 정하는 절편입니다.

x 새 입력ŷ 예측값w 기울기b 절편
분류: wx + b = 0

두 종류의 점을 가장 잘 나누는 경계선을 찾습니다. 새 점이 선의 어느 쪽에 있는지 보고 정상/불량 같은 범주를 결정합니다.

연속 출력 → 회귀범주 출력 → 분류

둘 다 입력과 정답 예시를 보고 관계를 찾으므로 지도학습입니다. 달라지는 것은 정답 y의 형태와 그에 맞는 손실함수·평가지표입니다.

핵심 기준
산술 연산이 현실적인 의미를 가지면 수치형, 어느 그룹에 속하는지가 핵심이면 범주형입니다. 따라서 설비 ID 101과 102는 숫자로 저장돼도 “102가 101보다 1만큼 큰 설비”가 아니므로 범주형입니다.

1. 핵심 유형: 수치형과 범주형

📏 수치형 · Numerical

크기와 차이가 실제 양을 나타냅니다.

구분판별 기준산업 예시
연속형
Continuous		구간 안에서 실수값을 가질 수 있음온도 73.4℃, 압력 2.18 bar, 순도 99.2%
이산형
Discrete		하나씩 셀 수 있는 정수값불량 개수, 정지 횟수, 주문 건수

암기한 모델

일반화한 모델

두 클래스 사이에 충분한 margin을 두고 핵심 패턴을 배워, 보지 못한 데이터에도 판단이 유지됩니다.

교수님의 Domain Adaptation 연결
학습 분포가 실제 현장 분포와 달라지면 기존 decision boundary를 그대로 적용할 수 없습니다. 조명·원료·설비·계절 변화로 이동한 분포를 학습 도메인과 정렬하거나 새 도메인에 모델을 적응시켜야 합니다.

데이터가 모델보다 먼저인 이유

Balance · 균형99:1 데이터에서는 모두 정상이라고 해도 accuracy가 99%가 됩니다.
Quantity · 양충분한 표본과 augmentation으로 변동을 학습합니다.
Overfitting 신호: Training 성능은 계속 좋아지는데 Validation 성능이 떨어지기 시작하면, 모델이 일반 규칙보다 훈련 데이터의 세부를 외우고 있다는 신호입니다.

🔍 수식은 기호가 아니라 장면으로 읽기

ŷ = w·x + b

입력 x마다 중요도 w를 곱해 모으고, 기본값 b를 더해 모델의 예측 ŷ을 만듭니다.

x 입력 특징w 특징별 중요도b 기본 보정ŷ 모델 예측
L = (y − ŷ)²

진짜 정답 y와 예측 ŷ의 차이를 제곱한 “틀린 정도”입니다. 차이가 클수록 더 강하게 벌점을 줍니다.

y 진짜 정답ŷ 예측L 손실
w ← w − α · ∂L/∂w

현재 w에서 손실이 올라가는 방향(기울기)의 반대로 α만큼 작은 발걸음을 옮깁니다.

α 학습률·보폭∂L/∂w 경사← 새 값으로 갱신
모든 학습 알고리즘의 세 부품
Model은 표현 가능한 답의 모양, Loss는 무엇을 틀렸다고 볼지, Optimizer는 손실을 줄이는 파라미터 탐색법입니다.

⛰️ Gradient Descent를 산 내려가기처럼 읽기

업데이트 식

w ← w − α · ∂L/∂w

손실이 커지는 방향을 미분으로 확인하고 그 반대로 이동합니다.

∂L/∂w(파셜 엘 오버 파셜 더블유)는 w를 조금 키웠을 때 loss가 증가하는지 감소하는지 알려주는 국소 기울기입니다.

α가 너무 작다

안정적이지만 최소점까지 매우 느리게 이동합니다.

α가 적절하다

손실을 안정적으로 빠르게 줄입니다.

α가 너무 크다

최소점을 뛰어넘으며 진동하거나 발산할 수 있습니다.

한 문장: Training은 training data의 평균 loss가 작아지도록 optimizer가 model parameter를 반복해서 갱신하는 과정입니다. 구체적인 미분 계산은 Lecture 04에서 이어집니다.

🧩 정답이 없을 때: K-means와 PCA

둘 다 label 없이 데이터 구조를 찾지만, K-means는 “누가 같은 무리인가?”, PCA는 “어느 방향이 정보를 가장 잘 보존하는가?”를 묻습니다.

K-means Clustering · 중심을 옮기며 무리를 찾기

1. 중심 K개 놓기초기 centroid를 임의로 선택
2. 가장 가까운 중심에 배정보통 Euclidean distance 사용
3. 중심 다시 계산각 cluster sample의 평균으로 이동
4. 수렴까지 반복배정이나 중심이 거의 변하지 않으면 종료

입력

label 없는 n개의 feature vector와 cluster 수 K

최적화 목표

각 sample과 소속 centroid 사이의 제곱거리 합을 작게 만듭니다.

주의

K를 사람이 정하며 초기 중심, scaling, outlier, 둥글지 않은 cluster에 민감합니다.

J = Σᵢ ||xᵢ − μc(i)||²

xᵢ(엑스 아이)는 sample, μc(i)(뮤 씨 아이)는 그 sample이 속한 cluster의 centroid입니다. 모든 sample이 자기 중심과 가까워지도록 J를 줄입니다.

PCA · 가장 넓게 퍼지는 축으로 투영하기

→

N차원 → K차원

y = Uᵀx

원본 x를 K개의 단위 projection axis로 투영해 더 작은 y로 바꿉니다.

K는 N보다 작고, 각 축은 서로 직교하며 데이터의 분산을 많이 보존하는 순서로 선택합니다.

좋은 축의 조건

투영된 값이 최대한 넓게 퍼져야 sample 구분 정보가 유지됩니다. 즉 projection 결과의 variance가 최대인 축을 찾습니다.

수학적 결론

데이터 covariance matrix Σ의 eigenvector가 주성분 축이고, 대응 eigenvalue가 그 축이 보존하는 variance입니다. 큰 eigenvalue 순서로 K개를 고릅니다.

maximize Var(uᵀx), subject to uᵀu = 1
Σu = λu

u(유)는 길이가 1인 투영축, Σ(시그마)는 공분산행렬, λ(람다)는 해당 축의 고유값입니다. “단위축 중 투영 분산을 가장 크게 만드는 축은 공분산행렬의 고유벡터”라고 읽습니다.

① Centering각 feature 평균을 빼 원점을 맞춤
② Covariance데이터가 함께 퍼지는 방향 계산
③ Eigen decomposition주요 축과 보존 variance 계산
④ Projection큰 eigenvalue의 축 K개로 압축

🙂 Eigenface · 얼굴 압축과 인식

200×200 얼굴은 40,000차원입니다. PCA의 주요 얼굴 축 몇 개에 투영하면 얼굴을 소수 coefficient로 표현할 수 있습니다. 학습 얼굴과 새 얼굴의 coefficient vector를 비교해 가장 가까운 사람을 찾을 수 있습니다.

비유의 한계: PCA는 label이나 의미를 보지 않고 variance만 최대화합니다. 분산이 큰 조명 변화가 신원보다 강하면 그 방향을 먼저 보존할 수도 있습니다.

선형회귀경사하강일반화K-meansPCA평가 설계

1. 선형회귀는 “점과 직선 사이의 오차”를 최소화한다

샘플이 n개이고 feature가 d개라면 입력 전체를 행렬 X∈ℝn×d, 정답을 벡터 y∈ℝn, 학습할 weight를 w∈ℝd로 묶을 수 있습니다.

ŷ = Xw + b
L(w,b) = (1/n) Σᵢ(yᵢ - ŷᵢ)² 읽기: 모든 샘플의 예측 오차를 제곱해 평균낸 MSE가 가장 작아지는 w와 b를 찾는다.

왜 차이를 제곱하나?

양수·음수 오차가 상쇄되지 않고, 큰 실수에 더 큰 벌점을 주며, 미분이 매끄러워 최적화하기 좋습니다.

왜 평균을 내나?

데이터 수가 달라도 loss 크기를 비교하기 쉬우며, 전체 데이터에서 평균적으로 잘 맞는 파라미터를 찾습니다.

한계는?

outlier의 오차도 제곱되므로 영향이 매우 큽니다. 이상치가 많은 공정에는 MAE·Huber loss도 검토합니다.

한 샘플이 weight에 보내는 신호

∂L/∂w = -(2/n) Xᵀ(y - ŷ) 잔차 y-ŷ가 크고 feature 값도 큰 샘플일수록 weight 업데이트에 강한 영향을 줍니다. 그래서 scaling과 label quality가 중요합니다.
교수님의 “미꾸라지 label”을 수식으로 읽으면: 틀린 label은 큰 잔차를 만들어 gradient 방향을 왜곡합니다. 다만 현대 학습에서는 모든 정답 샘플의 gradient도 계속 존재하므로 “맞은 샘플은 전혀 업데이트에 관여하지 않는다”기보다, loss와 confidence에 따라 기여도가 달라진다고 이해하는 것이 정확합니다.

선형회귀 MSE처럼 그릇 모양이면 적절한 조건에서 전역 최소점에 도달할 수 있습니다.

신경망은 굴곡·평탄부·saddle point가 많아 전역 최소점을 보장하지 않습니다. 실무에서는 충분히 좋은 해를 찾습니다.

3. 일반화는 모델 복잡도와 데이터 증거의 균형이다

Underfitting · 높은 Bias

모델이 너무 단순해 training pattern조차 설명하지 못합니다. Train·Validation error가 모두 큽니다.

적절한 복잡도

핵심 패턴을 설명하면서 noise는 따라가지 않습니다. Validation error가 가장 작습니다.

Overfitting · 높은 Variance

training noise까지 외워 Train error는 작지만 Validation error가 다시 증가합니다.

Expected Test Error ≈ Bias² + Variance + Irreducible Noise 테스트 오차는 단순해서 생기는 편향, 데이터 변화에 민감해서 생기는 분산, 데이터 자체의 제거 불가능한 잡음으로 생각할 수 있습니다.

4. K-means는 두 단계를 번갈아 목적함수를 낮춘다

min{Cₖ},{μₖ} J = Σₖ Σxᵢ∈Cₖ ||xᵢ - μₖ||² 각 샘플과 소속 cluster 중심 사이의 제곱거리 합, 즉 within-cluster sum of squares를 최소화한다.

Assignment step

cᵢ ← argminₖ ||xᵢ-μₖ||²

현재 중심을 고정하고 각 샘플을 가장 가까운 cluster에 배정합니다.

Update step

μₖ ← (1/|Cₖ|)Σxᵢ∈Cₖxᵢ

현재 배정을 고정하고 각 cluster의 평균을 새 중심으로 사용합니다.

각 단계는 현재 상대 변수를 고정했을 때 J를 증가시키지 않으므로 알고리즘은 수렴합니다. 하지만 시작점에 따라 서로 다른 local optimum에 도달할 수 있어 k-means++ 초기화와 여러 번의 재시작을 사용합니다.

5. PCA는 투영 후 분산 최대화와 복원 오차 최소화가 같은 문제다

먼저 각 feature 평균을 빼 X를 중심화합니다. 단위벡터 u 방향으로 투영된 한 sample의 좌표는 y=uᵀx이고, 전체 투영값의 분산은 uᵀΣu입니다.

maximizeu uᵀΣu   subject to   uᵀu=1

길이 제약이 없으면 u를 무한히 키워 분산도 무한히 키울 수 있으므로 u를 단위벡터로 제한합니다. Lagrange multiplier λ를 사용하면 다음과 같습니다.

ℒ(u,λ)=uᵀΣu - λ(uᵀu-1)
∂ℒ/∂u=0 ⇒ Σu=λu 따라서 좋은 투영축 u는 covariance matrix Σ의 eigenvector이고, 그 축의 분산은 eigenvalue λ입니다.
① CenterXc = X - μ
② CovarianceΣ = XcᵀXc/(n-1)
③ Sortλ가 큰 eigenvector 순서
④ ProjectZ = XcUₖ

Explained Variance Ratio

EVRₖ = λₖ / Σⱼλⱼ

선택한 주성분이 전체 분산 중 얼마를 보존하는지 나타냅니다. 누적 EVR로 K를 정할 수 있습니다.

Approximate Reconstruction

X̂ = ZUₖᵀ + μ

저차원 표현 Z를 원래 공간으로 되돌립니다. K가 작을수록 압축은 크지만 복원 손실도 증가합니다.

PCA가 실패하기 쉬운 경우: feature scale을 맞추지 않은 경우, 의미 있는 구조가 비선형인 경우, 분산이 큰 nuisance가 실제 예측 신호보다 강한 경우입니다. PCA는 label을 보지 않으므로 분류에 중요한 작은 분산 방향을 버릴 수도 있습니다.

신경망이 특징 추출과 판단을 함께 학습합니다. 깊은 층을 지날수록 현재 문제에 유용한 표현으로 바뀝니다.

딥러닝 계산의 기본 = 곱하기 + 더하기 + 비선형 변환의 반복

GPU가 강한 이유는 이런 대규모 행렬 계산을 많은 연산 장치가 병렬로 처리하기 때문입니다.

📦 모수 모델과 비모수 모델

Parametric Model · 모수 모델

학습 전에 모델의 형태와 조정할 파라미터 구조가 정해집니다. 선형회귀는 기울기와 절편을, 신경망은 고정된 구조 안의 가중치를 학습합니다.

예: Linear/Logistic Regression, Neural Network, Bayesian model

Non-parametric Model · 비모수 모델

데이터가 늘고 분포가 달라지면 모델의 실제 복잡도도 함께 변할 수 있습니다. “파라미터가 아예 없다”는 뜻은 아닙니다.

예: k-NN, Decision Tree, Random Forest

🏷️ 정답의 양으로 다시 보는 학습 방식

Supervised

모든 예시에 정답이 있습니다. 입력과 정답의 관계를 직접 학습합니다.

Semi-supervised

소량의 라벨과 대량의 무라벨 데이터를 함께 씁니다. 라벨 1%만 단독으로 학습할 때 생기는 과적합을 줄이는 데 유용합니다.

Unsupervised

정답 없이 거리·밀도·분산 같은 데이터 구조를 찾아 군집이나 저차원 표현을 만듭니다.

Cluster/Manifold Assumption
서로 가까이 모인 샘플은 같은 의미일 가능성이 높고, 실제 데이터는 고차원 공간 전체가 아니라 더 낮은 차원의 구조를 따라 놓인다는 가정입니다. 준지도학습은 무라벨 샘플을 흔들어도 예측이 일관되도록 만들며 이 구조를 학습할 수 있습니다.

⚖️ 회귀와 분류는 같은 직선을 다르게 읽는다

Regression · 회귀

연속값을 예측합니다. 직선의 기울기와 절편을 조절해 관측값과 예측값의 오차가 가장 작아지는 관계를 찾습니다.

예: 온도, 수율, 잔여 수명, 에너지 사용량

Classification · 분류

이산적인 범주를 예측합니다. 선이나 곡선의 어느 쪽에 있는지를 기준으로 정상/불량 같은 결정을 내립니다.

예: 정상/불량, 고장 유형, 제품 등급

회귀: 숫자의 크기 예측 · 분류: 범주의 경계 결정

전체 학습 흐름은 비슷하지만 출력 형태와 손실함수가 달라집니다.

🧯 오늘 수업에서 바로잡아야 할 표현

분류 경계 = 선형회귀?

직선이라는 직관은 비슷하지만 이진 분류에는 보통 logistic regression 같은 분류 모델을 씁니다. 선형회귀 출력을 그대로 class로 보는 것은 확률 범위와 loss 측면에서 적절하지 않을 수 있습니다.

비지도 cluster = 진짜 class?

K-means가 나눈 그룹은 거리 기준으로 만든 cluster입니다. 실제 의미 label이나 최적 정답임을 보장하지 않습니다.

Training 정확도가 낮으면?

먼저 underfitting·feature·label·model capacity를 점검합니다. Training 성능이 충분해야 일반화를 논할 수 있지만 100% 자체가 목표는 아닙니다.

NPU와 Inference

강의 녹취의 “MPU”는 문맥상 NPU로 이해하는 것이 자연스럽습니다. NPU는 신경망 추론의 행렬 연산을 효율적으로 처리하도록 설계된 가속기이며, 일부는 학습도 지원합니다.

✅ 내가 이해했는지 확인

Q. Training과 Inference는 어떻게 다른가?

Training(트레이닝·학습)은 많은 입력과 정답을 보고 모델 파라미터를 바꾸는 비싼 과정입니다. Inference(인퍼런스·추론)는 학습된 모델에 새 입력만 넣어 빠르게 출력을 얻으며 파라미터는 바뀌지 않습니다.

Q. 학습 데이터에서 100점이면 좋은 모델일까?

그것만으로는 알 수 없습니다. 외웠을 수 있기 때문입니다. 실제 목표는 보지 못한 새 데이터에서도 성능이 유지되는 Generalization(제너럴라이제이션·일반화)입니다.

Q. K-means와 PCA는 둘 다 비지도학습인데 무엇이 다른가?

K-means는 sample을 가까운 중심 기준으로 K개 그룹에 배정합니다. PCA는 sample을 그룹으로 나누지 않고, 데이터 분산을 가장 많이 보존하는 축을 찾아 차원을 줄입니다.
