규칙을 사람이 쓸 수 있으면 전통 프로그래밍, 규칙을 말로 쓰기 어렵지만 정답 예시는 많으면 머신러닝이 잘 맞습니다.

🧑‍💻 전통 프로그래밍

⇄

🧠 머신러닝

데이터 + 예시 정답 → 모델(배운 규칙)

손글씨 7처럼 규칙을 직접 쓰기 어려운 패턴을 예시로 학습합니다.

선택 기준 한 문장
정답 규칙이 “설명하기보다 보여주기 쉬울 때” 머신러닝의 가치가 큽니다. 단, 미래가 과거와 너무 다르거나 한 번의 오류도 허용할 수 없고 사람이 확인할 수도 없다면 적합성을 다시 검토해야 합니다.

🎙️ 교수님 설명으로 잡는 머신러닝의 본질

머신러닝은 결국 “곱하고 더할 숫자”를 데이터로 찾는 과정

입력 숫자들을 어떤 비율로 곱하고 더해야 원하는 출력이 나오는지 모델이 학습합니다. 딥러닝이 GPU에서 빠른 이유도 거대한 행렬의 곱셈과 덧셈을 병렬로 반복하기 때문입니다. 다만 이것은 계산의 모습이고, 학습의 목적은 새 데이터에도 통하는 관계를 찾는 것입니다.

Rule-based사람이 특징과 판단 규칙을 모두 작성
Classical ML사람이 특징을 만들고 모델이 경계를 학습
Representation Learning쓸 만한 특징 표현도 데이터에서 학습
Deep Learning여러 층에서 표현을 목적에 맞게 변환
김치찌개·밀키트 비유
원재료를 바로 완성품으로 바꾸는 것이 아니라 손질하고 볶고 끓이면서 요리에 알맞은 상태로 바꿉니다. 딥러닝의 각 층도 원시 입력을 문제 해결에 알맞은 feature representation(피처 레프리젠테이션·특징 표현)으로 단계적으로 바꿉니다.

🧭 데이터에 무엇이 들어 있나?

🏷️ Supervised Learning

지도학습 — 입력 x와 정답 y를 함께 보여주고, 새 입력의 정답을 예측하도록 학습합니다.

숫자 예측은 회귀, 범주 예측은 분류입니다.

🧩 Unsupervised Learning

비지도학습 — 정답 없이 입력만 보고 그룹·방향·압축 표현·이상점을 찾습니다.

K-means 군집화, PCA 차원축소가 대표적입니다.

🎮 Reinforcement Learning

강화학습 — 환경에서 행동하고 늦게 받는 보상을 바탕으로 장기 보상이 커지는 정책을 배웁니다.

로봇 제어·공정 스케줄링처럼 연속 의사결정에 씁니다.

📈 Regression · 회귀

온도, 가격, 배터리 잔여 수명처럼 연속적인 숫자를 예측합니다.

🗂️ Classification · 분류

정상/불량, 불량 종류처럼 이산적인 범주를 예측합니다. 회귀 결과에 문턱값을 적용해 분류할 수도 있지만 그 문턱값은 설계자가 책임져야 합니다.

📏 교수님이 그린 직선의 의미

회귀: ŷ = wx + b

키 x와 발 크기 y처럼 연속적인 관계를 가장 잘 설명하는 직선을 찾습니다. w는 직선의 기울기, b는 위아래 위치를 정하는 절편입니다.

x 새 입력ŷ 예측값w 기울기b 절편
분류: wx + b = 0

두 종류의 점을 가장 잘 나누는 경계선을 찾습니다. 새 점이 선의 어느 쪽에 있는지 보고 정상/불량 같은 범주를 결정합니다.

연속 출력 → 회귀범주 출력 → 분류

둘 다 입력과 정답 예시를 보고 관계를 찾으므로 지도학습입니다. 달라지는 것은 정답 y의 형태와 그에 맞는 손실함수·평가지표입니다.

산업 시계열 주의
시간 데이터는 미래가 과거로 새어 들어가지 않도록 무작위로 섞지 않고, 과거로 학습하고 미래로 테스트하는 분할이 기본입니다.

🔍 수식은 기호가 아니라 장면으로 읽기

ŷ = w·x + b

입력 x마다 중요도 w를 곱해 모으고, 기본값 b를 더해 모델의 예측 ŷ을 만듭니다.

x 입력 특징w 특징별 중요도b 기본 보정ŷ 모델 예측
L = (y − ŷ)²

진짜 정답 y와 예측 ŷ의 차이를 제곱한 “틀린 정도”입니다. 차이가 클수록 더 강하게 벌점을 줍니다.

y 진짜 정답ŷ 예측L 손실
w ← w − α · ∂L/∂w

현재 w에서 손실이 올라가는 방향(기울기)의 반대로 α만큼 작은 발걸음을 옮깁니다.

α 학습률·보폭∂L/∂w 경사← 새 값으로 갱신
z = (x − μ) / σ

x에서 평균 μ를 빼 중심을 0으로 옮기고 표준편차 σ로 나눠 단위를 맞춥니다.

🧩 정답이 없을 때: K-means와 PCA

K-means Clustering · 중심을 옮기며 무리를 찾기

1. 중심 K개 놓기처음 중심점을 임의 선택
2. 가까운 중심 찾기각 샘플을 가장 가까운 중심에 배정
3. 중심 다시 계산각 그룹 샘플 평균으로 중심 이동
4. 반복하기배정이 바뀌지 않을 때까지 2–3 반복

🎨 K-means의 그림

RGB 색 공간에 흩어진 픽셀을 가까운 색끼리 묶는 장면을 떠올리면 됩니다. 단, K를 사람이 정하고 크기 척도와 초기 중심에 영향을 받습니다.

📉 PCA의 그림

여러 차원에 퍼진 데이터를 가장 넓게 펼쳐진 방향으로 비춘 “그림자”입니다. 정보 손실을 최소화하며 N차원을 K차원(K≪N)으로 줄여 계산·저장·시각화를 쉽게 합니다.

✅ 내가 이해했는지 확인

Q. Training과 Inference는 어떻게 다른가?

Training(트레이닝·학습)은 많은 입력과 정답을 보고 모델 파라미터를 바꾸는 비싼 과정입니다. Inference(인퍼런스·추론)는 학습된 모델에 새 입력만 넣어 빠르게 출력을 얻으며 파라미터는 바뀌지 않습니다.

Q. 학습 데이터에서 100점이면 좋은 모델일까?

그것만으로는 알 수 없습니다. 외웠을 수 있기 때문입니다. 실제 목표는 보지 못한 새 데이터에서도 성능이 유지되는 Generalization(제너럴라이제이션·일반화)입니다.
