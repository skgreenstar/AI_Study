# AI 시각 백과사전 에이전트 템플릿

아래 프롬프트를 사용하는 AI 에이전트에 그대로 붙여 넣고 대괄호만 채운다.

~~~text
이 저장소는 여러 사람이 함께 확장하는 AI 시각 백과사전이다.

작업을 시작하기 전에 다음 파일을 순서대로 읽어라.
1. AGENTS.md
2. CONTRIBUTING.md
3. topics/diffusion-prerequisites.html
4. topics/_template.html
5. README.md

topics/diffusion-prerequisites.html은 최초의 diffusion_prerequisites_visual_guide.html을 저장소에 옮긴 공식 디자인 레퍼런스다.
새 페이지는 이 문서와 같은 색상 체계, 정보 밀도, 카드 구성, 흐름도 품질, 쉬운 설명, 수식 해부와 실무 연결 수준으로 작성하라.
제목과 문장만 바꾼 복제품을 만들지 말고, 새 주제의 관계에 맞는 시각화를 설계하라.

새 항목:
- 주제: [주제]
- 대상: [완전 입문자 / 대학생 / 현업 개발자]
- 목표: [이 문서를 읽고 할 수 있어야 하는 것]
- 난이도: [입문 / 기초 / 중급 / 심화 / 자동 판단]
- 선수지식: [문서 ID 또는 자동 판단]
- 기존 연결 항목: [문서 ID 또는 자동 판단]
- 강조: [그림과 직관 / 수식 해부 / 실무 사례 / 코드]

필수 작업:
- topics/_template.html을 복사하여 topics/[영문-kebab-case].html을 생성한다.
- 기존 파일은 사용자가 명시하지 않는 한 삭제하거나 축약하지 않는다.
- 한눈에 보는 큰 그림, 생활 비유와 한계, 핵심 개념 카드, 최소 수식 해부, 실제 AI 사례, 오해 바로잡기, 퀴즈 3문항, 연결 문서를 모두 채운다.
- 글만 있는 긴 구간을 만들지 말고, 관계가 있는 내용에는 흐름도·비교표·그래프·수식 대응 카드를 넣는다.
- 수식의 주요 기호마다 한국어 발음, 뜻, 역할과 문장으로 읽기를 제공한다.
- 실무 사례에는 입력, 모델이 배우는 것, 출력과 한계를 포함한다.
- 존재하는 내부 문서에만 링크하고 선수지식·관련·다음 문서를 양방향으로 연결한다.
- index.html과 README.md에 새 항목을 추가한다.
- 공식 문서 또는 원 논문 중심으로 출처와 확인일을 기록한다.
- 모바일 360px와 데스크톱 화면을 고려하고 가로 넘침이 없도록 한다.
- 빈 대괄호와 placeholder를 남기지 않는다.
- topic/[주제] 브랜치에 커밋하고 Pull Request 설명을 작성한다.

완료 보고에는 생성·수정한 파일, 연결한 문서, 추가한 시각 요소, 사용한 출처, 검증 결과를 포함한다.
~~~

## 최소 사용 예시

~~~text
이 저장소의 prompts/agent-template.md 지침대로 새 항목을 만들어줘.

주제: 조건부확률
대상: 완전 입문자
목표: p(A|B)를 읽고 디퓨전 역과정과 연결할 수 있기
난이도: 기초
선수지식: probability-distribution
기존 연결 항목: diffusion-prerequisites
강조: 그림과 직관, 수식 해부, 실무 사례
~~~
