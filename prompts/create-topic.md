# AI 시각 백과사전 공통 프롬프트

다음 블록에서 대괄호 부분만 바꾸어 사용합니다.

~~~text
AI 시각 백과사전에 [주제] 항목을 추가해줘.

대상: [완전 입문자 / 대학생 / 현업 개발자]
목표: [이 자료를 보고 이해해야 할 것]
난이도: [입문 / 기초 / 중급 / 심화]
선수지식: [자동 판단 또는 직접 입력]
기존 연결 항목: [관련 문서]
특별히 강조할 내용: [그림과 직관 / 수식 해부 / 코드 / 실무 사례]

기존 디자인 토큰과 문서 구조를 유지해줘.
기존 내용은 삭제하거나 축약하지 말고 새 항목을 자연스럽게 연결해줘.
페이지 순서는 한눈에 보는 큰 그림 → 생활 비유 → 핵심 개념 카드 → 최소 수식 해부 → 실제 AI 사용처 → 자주 하는 오해 → 3문항 체크퀴즈 → 이전·다음·관련 문서로 구성해줘.
글보다 SVG·CSS 도식·흐름도·비교표를 우선해줘.
수식의 모든 기호는 한국어로 읽는 법과 역할을 함께 써줘.
본문의 전문용어는 별도 용어사전으로 빼지 말고, 실제 등장 위치 옆에 작은 `i` 아이콘을 붙여줘. 아이콘을 누르면 영문 표기, IPA 실제 영어 발음, 한글 발음, 한글 뜻, 쉬운 개념 설명, 직관적 비유와 미니 흐름도가 그 자리에서 펼쳐지게 해줘.
공통 `assets/inline-terms.css`와 `assets/inline-terms.js`를 연결하고, 새 용어는 공통 정의에 추가해 다른 페이지에서도 재사용할 수 있게 해줘.
같은 용어는 페이지당 한 번만 표시하고, 제목·개념 카드·흐름도처럼 문맥이 명확한 위치에 배치해줘. 개수 제한은 두지 말고 실제 이해에 필요한 전문용어는 빠짐없이 다루되, 일반 문장 중간이나 이미 충분히 설명된 곳에는 중복 아이콘을 만들지 마.
최신 확인이 필요한 사실은 1차 출처로 검증하고 출처와 확인일을 표시해줘.
완료 후 링크 오류, 모바일 레이아웃, 색상 범례, 용어 일관성을 검사해줘.
~~~
