이미지 분류를
세 가지 관점으로 읽기

픽셀 거리만 비교하는 Nearest Neighbor의 한계를 확인하고, 하나의 Linear Classifier를 대수적·시각적·기하학적으로 해석한 뒤 점수를 확률로 바꾸는 Softmax까지 연결합니다.

① 핵심 요약

  1. 컴퓨터는 이미지를 픽셀 숫자로 보지만, 사람은 사물의 의미를 봅니다. 이 차이가 Semantic Gap입니다.
  2. Nearest Neighbor는 새 이미지와 훈련 이미지의 거리를 계산해 가장 가까운 이미지의 라벨을 사용하지만, 픽셀 거리가 의미적 유사성을 항상 반영하지는 않습니다.
  3. Linear Classifier는 s=Wx+b로 한 번의 행렬 연산을 통해 클래스별 점수인 logit을 만듭니다.
  4. 같은 W는 대수적으로는 점수 계산식, 시각적으로는 클래스 템플릿, 기하학적으로는 공간을 나누는 초평면으로 해석할 수 있습니다.
  5. Softmax는 logit을 합이 1인 확률로 바꾸고 Cross-Entropy는 정답 클래스의 확률이 작을수록 큰 손실을 부여합니다.

② 생활 비유: 사진 찾기와 채점표

Nearest Neighbor는 가장 닮은 사진 찾기

새 사진을 받으면 앨범의 모든 사진과 비교해 가장 가까운 사진의 이름을 빌려옵니다.

비유의 한계: 사람은 형태와 의미를 비교하지만 단순한 픽셀 거리는 위치·밝기 변화까지 큰 차이로 계산합니다.

Linear Classifier는 클래스별 채점표

고양이·자동차·새마다 서로 다른 채점 기준 W를 갖고, 입력 이미지가 각 기준에 얼마나 맞는지 점수를 냅니다.

비유의 한계: 실제 W는 사람이 규칙을 작성한 표가 아니라 데이터로부터 학습되는 수치 행렬입니다.

③ 문제: 픽셀과 의미 사이의 간극

출발점

Semantic Gap

컴퓨터의 관점: 이미지는 H×W×C개의 숫자 배열입니다.

사람의 관점: 고양이의 자세·표정·배경이 달라도 같은 ‘고양이’로 인식합니다.

문제: 의미는 같은데 픽셀은 크게 달라질 수 있고, 픽셀은 비슷한데 의미는 다를 수도 있습니다.

비교 기준

Distance Metric

L₁(x,y)=Σᵢ|xᵢ−yᵢ|
L₂(x,y)=√Σᵢ(xᵢ−yᵢ)²

L₁: 좌표별 차이의 절댓값을 더한 거리. Manhattan distance라고도 합니다.

L₂: 차이를 제곱해 더한 뒤 제곱근을 취한 직선거리. Euclidean distance입니다.

핵심: 거리 공식 자체보다 “어떤 표현 공간에서 거리를 재는가”가 중요합니다. 픽셀 공간보다 학습된 특징 공간이 의미를 더 잘 반영할 수 있습니다.

판단가장 가까운 1개가까운 K개의 다수결

Lazy learning: 훈련 때는 데이터를 저장할 뿐이지만 예측 때 모든 훈련 샘플과 거리를 계산하므로 느립니다. 차원이 커질수록 거리의 구분력이 약해지는 문제도 있습니다.

⑤ Linear Classifier: 하나의 모델, 세 가지 관점

s = Wx + b
x
엑스 · 펼친 이미지 벡터
W
더블유 · 클래스별 가중치
b, s
바이어스와 클래스별 logit
문장으로 읽기: 입력 벡터 x에 가중치 행렬 W를 곱하고 편향 b를 더해 각 클래스의 점수 s를 계산합니다.

차원 예시: x∈ℝᴰ, W∈ℝᴷ×ᴰ, b∈ℝᴷ이면 출력 s∈ℝᴷ입니다. K는 클래스 수입니다.

Algebraic viewpoint

행렬식으로 보기

W의 k번째 행 wₖ는 k번째 클래스의 채점 기준입니다. sₖ=wₖᵀx+bₖ가 클수록 입력이 해당 클래스 기준에 잘 맞는다고 봅니다.

Visual viewpoint

클래스 템플릿으로 보기

wₖ를 원래 이미지 모양으로 reshape하면 클래스의 대표 패턴처럼 시각화할 수 있습니다. 입력과 wₖ의 내적은 두 패턴이 얼마나 같은 방향인지 측정합니다.

한계: 클래스마다 템플릿 하나만 가지므로 다양한 자세와 배경을 한 장의 평균적 모습으로 뭉갤 수 있습니다.
Geometric viewpoint

초평면으로 보기

wᵀx+b=0은 특징 공간을 둘로 나누는 hyperplane입니다. 점이 어느 쪽에 있는지에 따라 클래스 점수가 달라집니다.

Linear limitation

직선 하나로 못 나누는 경우

분면이 교차하는 XOR 배치나 중심과 바깥을 구분하는 도넛 모양은 하나의 직선·평면으로 완벽히 분리할 수 없습니다. 복잡한 이미지도 대체로 선형 분리가 완벽하지 않습니다.

딥러닝의 역할: 여러 비선형 층으로 입력을 더 잘 분리되는 특징 공간으로 변환한 뒤 마지막에 선형 분류기를 사용합니다.
★ 이번 수업의 범위: 좋은 W가 이미 주어졌다고 가정하고 W가 무엇을 의미하는지 해석했습니다. W를 데이터로부터 어떻게 학습하는지는 손실함수와 최적화에서 이어서 다룹니다.

⑥ Softmax와 Cross-Entropy

Logit을 확률로

P(y=k|x)=esₖ / Σⱼesⱼ

Softmax는 임의의 실수 점수들을 모두 양수로 만들고 합이 1이 되도록 정규화합니다. 가장 큰 logit이 가장 큰 확률을 얻습니다.

sₖ
k클래스 logit
esₖ
큰 점수를 더 강조
Σⱼ
전체 합으로 나눔

정답 확률을 높이도록

L = −log P(y|x)

Cross-Entropy loss는 정답 클래스의 확률이 1에 가까우면 작아지고, 0에 가까우면 매우 커집니다.

연결: Wx+b가 logit 생성 → Softmax가 확률 변환 → Cross-Entropy가 틀린 정도 계산 → 다음 수업에서 W를 수정합니다.
Softmax와 Sigmoid 구분: 한 이미지가 하나의 클래스에만 속하는 다중 클래스 분류에는 Softmax가 자연스럽습니다. 여러 라벨이 동시에 참일 수 있는 다중 라벨 분류에는 클래스별 Sigmoid를 사용합니다.

⑦ 실제 AI에서는 어디에 쓰이나?

이미지 검색

문제: 질의 이미지와 의미가 비슷한 이미지를 찾습니다.

입력: 이미지의 특징 벡터

배우는 것: 의미가 비슷한 이미지가 가까워지는 표현

출력: 거리순 검색 결과

개념 연결: 특징 공간에서 Nearest Neighbor를 적용합니다.

한계: 특징 표현이 편향되면 검색 결과도 편향됩니다.

사진 분류

문제: 이미지가 어떤 클래스인지 예측합니다.

입력: 픽셀 또는 신경망 특징 벡터

배우는 것: 클래스를 구분하는 W와 특징 표현

출력: 클래스별 logit과 Softmax 확률

개념 연결: 마지막 층이 Linear Classifier 역할을 합니다.

한계: 확률이 높아도 실제 신뢰도가 잘 보정됐다는 뜻은 아닙니다.

⑧ 자주 하는 오해

픽셀 거리가 작으면 의미도 비슷하다?
밝기나 위치가 조금만 달라도 픽셀 거리는 커질 수 있습니다. 의미 유사성은 표현 공간에 달려 있습니다.
Linear Classifier는 곡선 경계를 만든다?
원래 입력 공간에서는 선형 경계만 만듭니다. 비선형 특징 변환이 앞에 있어야 복잡한 경계를 표현할 수 있습니다.
W의 시각화가 실제 물체 사진이다?
W는 점수를 높이는 방향을 나타내는 가중치 템플릿이며 실제 평균 이미지와 동일하지 않습니다.
Softmax 출력은 항상 믿을 만한 확률이다?
합이 1인 상대 점수이지만 모델이 과신할 수 있습니다. 확률 보정과 분포 변화 검토가 필요합니다.

⑨ 확인 퀴즈

Q1. 같은 고양이 사진을 오른쪽으로 몇 픽셀 이동했을 때 L₂ 거리는 커질 수 있는데 사람은 같은 고양이라고 판단합니다. 무엇을 보여주는 예인가요?
정답: Semantic Gap과 픽셀 기반 Distance Metric의 한계입니다. 픽셀 배열의 차이와 사람이 이해하는 의미의 차이는 일치하지 않을 수 있습니다.
Q2. W의 k번째 행을 Algebraic·Visual·Geometric 관점에서 각각 설명해 보세요.
정답: 대수적으로는 k클래스 점수를 계산하는 가중치 벡터, 시각적으로는 k클래스의 템플릿, 기하학적으로는 클래스 점수와 결정경계를 정하는 초평면의 법선 벡터입니다.
Q3. 정답 클래스의 Softmax 확률이 0.9에서 0.1로 낮아지면 Cross-Entropy loss는 어떻게 변하나요?
정답: L=−log P(y|x)이므로 손실이 크게 증가합니다. 모델이 정답에 낮은 확률을 주었기 때문에 더 큰 벌점을 받습니다.
