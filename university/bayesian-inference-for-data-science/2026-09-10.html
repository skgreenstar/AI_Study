닮은 점: 단순가설은 모수 하나를 지정합니다. 복합가설은 가능한 모수들에 사전확률을 나누고, 각 모수가 관측을 설명하는 정도를 평균합니다. 많은 후보 중 가장 잘 맞는 하나만 고르는 방식과 결과가 다릅니다.

비유의 한계: 실제 온도에는 계절·지역·시간 의존성이 있습니다. 여기서는 지정된 정규 오차와 두 가설 안에서만 비교합니다. 베이즈 요인이 크다고 후보 가설이 현실을 완벽히 설명하는 것은 아닙니다.

③ 핵심 개념 카드

★ 9월 8일에서 이어짐

Bayes Factor · 베이즈 요인

정의: B₁₀=m₁(x)/m₀(x). 관측이 H₁과 H₀의 사전 오즈를 바꾸는 배수입니다.

왜 중요한가: 가설 자체의 사전확률과 데이터가 주는 증거를 구분합니다.

사전 오즈×B₁₀→사후 오즈

예: B₁₀=10, 사전 오즈=1/9이면 사후 오즈=10/9입니다.

★ 평균한 적합도

Marginal Likelihood · 주변가능도

정의: 가설 내부의 사전분포로 가능도를 평균한 값입니다.

왜 중요한가: 복합가설에서 아직 모르는 θ를 적분해 데이터에 대한 예측을 만듭니다.

θ의 후보→가능도 × 사전 가중치→적분

예: θ가 정규분포를 따르면 x̄의 주변분산에는 θ의 불확실성도 더해집니다.

점귀무가설

Dirac Measure · 디락측도

정의: 한 점 θ₀에 확률 1을 두는 확률측도입니다. 보통의 연속 확률밀도 함수처럼 높이를 읽으면 안 됩니다.

왜 중요한가: 연속 사전분포만으로는 확률이 0인 θ=θ₀에 별도의 가설 확률 π₀를 줄 수 있습니다.

H₀: θ=θ₀
점질량 π₀+H₁: θ≠θ₀
연속 부분 π₁

예: π₀=π₁=0.5인 점질량·연속분포 혼합.

★ 실습의 연결 고리

Logistic Function · 로지스틱 함수

정의: 실수 a를 1/(1+e⁻ᵃ)로 바꾸어 0과 1 사이로 보냅니다.

왜 중요한가: a가 로그 사후 오즈이면 결과가 H₁의 사후확률입니다.

로그 사전 오즈+로그 B₁₀→확률

예: a=0이면 0.5. 절댓값이 커질 때 직접 지수를 나누기보다 안정적인 함수를 씁니다.

★ 고정 조건 확인

Jeffreys–Lindley Paradox · 제프리스–린들리 역설

정의: 고정된 유의한 z값에서 표본 수를 늘릴 때, p값은 같지만 베이즈 요인은 점귀무가설을 점점 더 지지할 수 있는 현상입니다.

왜 중요한가: p값과 가설의 사후확률이 서로 다른 질문에 답한다는 것을 보여줍니다.

예: z=1.96, σ=τ=1인 계산을 아래에서 비교합니다.

★ 분산을 모르는 실습

JZS Prior · JZS 사전분포

정의: Jeffreys–Zellner–Siow 사전분포. 효과크기 δ에 코시 사전분포를 주고 공통 미지 분산도 함께 처리합니다.

왜 중요한가: σ²를 모르는 정규평균 검정에서 베이즈 요인을 계산하는 구체적 선택입니다.

예: 동일한 10명의 수면시간 차이를 이용한 베이지안 대응표본 t 검정.

실험 1 · 관측값과 오차를 바꿔보기

H₀:θ=0, H₁:θ=10은 그대로 두고 표준편차 σ와 사전확률을 바꿉니다. 분산은 σ²입니다.

보라 실선: P(H₁|x) · 분홍 점선: P(H₀|x) · 세로선: 선택한 관측값

일반화한 로그 사후 오즈는 log[π₁/(1−π₁)]+(10x−50)/σ²입니다. σ가 커지면 같은 관측값의 증거가 약해져 곡선이 완만해집니다. 사전확률이 다르면 50% 교차점도 이동합니다.

C. 단순가설 대 복합가설: 평균이 θ₀와 다른가?

녹취 18:56–29:04 · week2.pdf 15–19쪽

서로 독립인 X₁,…,Xₙ|θ∼N(θ,σ²), σ²는 알려짐을 가정합니다. H₀:θ=θ₀, H₁:θ≠θ₀이고 H₁ 안에서 θ∼N(θ₀,τ²), τ²>0을 사용합니다.

H₁의 정규밀도는 θ₀에서 양수여도 그 한 점의 확률은 0입니다. 따라서 θ≠θ₀와 모순되지 않습니다. H₀의 점질량과 연속밀도의 높이를 혼동하지 마세요.

D. 제프리스–린들리 역설: 무엇을 고정하나요?

녹취 29:04–33:02 · week2.pdf 20쪽 · 조건을 명시한 복습 보충

고정: 유의한 z값, σ, τ>0, 두 가설의 양의 사전확률. 변화: n 증가. 그러면 |x̄−θ₀|=zσ/√n은 작아집니다. 슬라이드의 “기각역이 0에 가까워진다”는 말은 원래 평균 차이 척도의 임계값에 해당하며, z 척도의 임계값 1.96 자체가 줄어드는 것은 아닙니다.
n → ∞ ⇒ κ → ∞
(1+κ)⁻¹ᐟ² → 0,  exp{z²κ/[2(1+κ)]} → exp(z²/2)
B₁₀ → 0,  P(H₀|x) → 1

읽기: 엔이 무한대로 갈 때 카파도 커지고, 첫 인자는 0으로, 둘째 인자는 유한한 상수로 갑니다. 따라서 비 일공은 0으로 갑니다. 의미: p값이 고정되어도 가설 사후확률은 달라질 수 있습니다.

dσ²를 기준으로 한 밀도

문장으로 읽기: 평균 차이를 표준편차 단위로 표현한 효과크기에 코시분포를 두고, 미지 분산을 두 가설에서 공통으로 다룹니다. 필요한 이유: 평균 차이뿐 아니라 분산의 불확실성도 검정에 반영하기 위해서입니다.

Cauchy Distribution · 코시분포

중심 주변이 높지만 정규분포보다 꼬리가 두꺼운 분포입니다. 전체 확률은 1인 proper 사전분포입니다.

녹취의 “기댓값이 무한대”는 정확히는 기댓값이 정의되지 않는다로 고칩니다. 양·음의 꼬리 적분이 각각 발산하므로 대칭이라고 평균 0이 되는 것은 아닙니다.

Improper Prior · 부적절 사전분포

∫₀∞(1/v)dv가 발산하므로 v=σ²에 대한 1/v는 적분값을 1로 만들 수 없습니다.

임의의 improper 사전을 모형마다 다르게 넣어도 된다는 뜻이 아닙니다. 여기서는 두 모형의 공통 분산에 같은 사전을 사용하는 JZS 구성입니다. 일반적인 베이즈 요인에서는 정의되지 않은 상수가 문제가 됩니다.

계층 표현(슬라이드): r=1일 때 g∼Inverse-χ²₁, δ|g∼N(0,g)를 두면 주변분포가 Cauchy(0,1)입니다. g(지)는 양의 잠재 분산, Inverse-χ²₁(인버스 카이 스퀘어 원)은 자유도 1인 역카이제곱분포입니다. g=1/U, U∼χ²₁로 정의하면 척도가 명확합니다. 전체 주변가능도 적분 전개는 생략하고 아래 함수로 계산합니다.

⑤ R 실습과 AI 활용

녹취 속 R 시연을 재구성한 복습 코드입니다. 원본 .R 파일을 그대로 옮긴 것은 아닙니다.

1. 로그 가능도에서 사후확률로

# X | theta ~ N(theta, sigma^2), theta = 0 or 10
x <- seq(0, 10, length.out = 401)
sigma <- 1
prior1 <- 0.5
log_B10 <- dnorm(x, mean = 10, sd = sigma, log = TRUE) -
           dnorm(x, mean = 0, sd = sigma, log = TRUE)
post1 <- plogis(qlogis(prior1) + log_B10)
matplot(x, cbind(1 - post1, post1), type = "l",
        lty = c(2, 1), col = c("#ef6797", "#7357e8"),
        xlab = "Observed x", ylab = "Posterior probability")
legend("right", c("H0", "H1"), lty = c(2, 1),
       col = c("#ef6797", "#7357e8"))

dnorm의 sd에는 분산이 아닌 표준편차를 넣습니다. 로그 밀도의 차이는 로그 B₁₀이고 qlogis는 로그 사전 오즈, plogis는 역변환입니다. 강의에서는 직접 exp를 계산할 때의 수치 문제를 강조했습니다. 함수 정의: R 공식 Logistic 문서.

2. sleep 자료: 동일한 10명의 차이를 비교한다

문제: 두 수면제 조건의 평균 차이가 0인가? 입력: 동일한 사람의 두 조건에서 측정한 수면 증가 시간. 20명의 독립 표본이 아니라 10쌍입니다. R 공식 데이터 설명.

ID로 두 조건 연결→약 2 − 약 1
차이 10개→JZS 검정
B₁₀ 확인
# 처음 한 번만: install.packages("BayesFactor")
library(BayesFactor)
data(sleep)
# 행 순서에 의존하지 않고 ID로 두 조건을 맞춥니다.
wide <- reshape(sleep, idvar = "ID", timevar = "group",
                direction = "wide")
d <- wide$extra.2 - wide$extra.1
stopifnot(length(d) == 10L, !anyNA(d))
t.test(d, mu = 0, alternative = "two.sided")
bf_medium <- ttestBF(x = d, mu = 0, rscale = "medium")
bf_slide <- ttestBF(x = d, mu = 0, rscale = 1)
bf_medium
bf_slide
B10 <- as.vector(bf_medium)[1]
prior1 <- 0.5
post1 <- plogis(qlogis(prior1) + log(B10))
c(B10 = B10, posterior_H1 = post1)
packageVersion("BayesFactor")
슬라이드와 실습의 추가 확인 사항: 슬라이드 21쪽은 r=1인 Cauchy(0,1)입니다. 패키지 기본 rscale="medium"은 r=√2/2이므로 같은 사전분포가 아닙니다. 위 코드는 두 설정을 모두 비교합니다. 패키지 저자의 ttestBF 도움말.

녹취에서 약 17.5가 언급되지만 원본 코드의 척도·출력은 확인되지 않았습니다. 이를 모든 설정의 재현값으로 고정하지 않습니다. ttestBF 출력은 H₁/H₀의 베이즈 요인이며, 동일한 가설 사전확률을 가정할 때만 사후 오즈와 같습니다. 패키지 저자의 실습 설명.

해석: 양측 대립가설의 지지는 “평균 차이가 0이 아니다”에 대한 증거입니다. 차이의 방향·크기는 효과크기 사후분포로 별도로 살핍니다. 정규성, 극단값, 사람 사이의 독립성, 사전 척도에 대한 민감도를 함께 확인합니다. 이 R 코드는 현재 환경에서 직접 실행하지 못했습니다.

⑥ 자주 하는 오해와 시험 점검

p=0.05이면 H₀의 확률이 5%다?
p값은 H₀ 아래의 꼬리확률입니다. 가설 사후확률에는 가설 사전확률과 두 가설의 주변가능도가 필요합니다.
단순가설의 가능도 비를 복합가설에도 그대로 쓰면 된다?
복합가설은 사전분포를 따라 가능도를 적분해야 합니다. 최대로 잘 맞는 θ 하나만 대입하면 다른 비교가 됩니다.
사전분포를 넓게 잡으면 항상 더 객관적이다?
사전 척도 τ나 r는 주변가능도에 영향을 줍니다. 문제에 맞는 척도와 민감도 확인이 필요합니다.
베이즈 요인이 크면 차이도 크다?
가설 증거와 효과크기는 다릅니다. 차이의 실제 크기와 불확실성을 함께 보고합니다.

⑦ 확인 퀴즈 3문항

Q1. θ=0 대 θ=10, 분산 1, 같은 사전확률일 때 x=5라면 두 가설의 사후확률은?
각각 0.5입니다. log B₁₀=10×5−50=0이므로 B₁₀=1입니다. 사전 오즈 1이 그대로 유지됩니다.
Q2. 제프리스–린들리 역설에서 n을 늘릴 때 z와 |x̄−θ₀|를 둘 다 고정할 수 있나요?
σ가 고정되고 z가 0이 아니면 불가능합니다. z=|x̄−θ₀|√n/σ이므로 z를 고정하려면 평균 차이가 1/√n에 비례해 줄어야 합니다.
Q3. sleep을 독립적인 20명으로 분석하고 기본 rscale로 실행하면 슬라이드의 JZS 예제를 그대로 재현한 걸까요?
아닙니다. 동일한 10명의 대응 자료이므로 ID별 차이를 사용해야 합니다. 기본 medium은 r=√2/2이고 슬라이드의 Cauchy(0,1)은 r=1이므로 척도도 명시해야 합니다.
